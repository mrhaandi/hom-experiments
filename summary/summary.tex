\section{Bounded Parallel Intersection Type System}

We denote \emph{intersection types} by $A, B$, finite sets of intersection types by $\sigma, \tau$, and \emph{type atoms} by $a, b$.

\begin{definition}[Intersection Types]
\label{def:itypes}
$\begin{array}{rcl}
A, B &::=& a \mid \sigma \to A\\
\sigma, \tau &::=& \{A_1, \ldots, A_n\} \text{ where } n \geq 0
\end{array}$
\end{definition}

An \emph{environment}, denoted by $\Gamma$, is a finite set of \emph{type assumptions} having the shape $x : \sigma$ for distinct term variables.
\begin{definition}[Environment]
$\Gamma ::=\{x_1 : \sigma_1, \ldots, x_n : \sigma_n\}$ where $x_i \neq x_j$ for $i \neq j$.
\end{definition}
We may extend an environment $\Gamma$ by an additional assumption $x : \sigma$, written $\Gamma, x : \sigma$, where $x$ does not appear in any assumption in $\Gamma$.

We denote vectors of types and sets of types by $\bar{A}$ and $\bar{\sigma}$ respectively.
If $\bar{\sigma} = (\sigma_1, \ldots, \sigma_n)$ and $\bar{A} = (A_1, \ldots, A_n)$, then $\sigma \Rightarrow A = (\sigma_1 \to A_1, \ldots, \sigma_n \to A_n)$.

Extending notation~\cite{DudenhefnerU21} from surjective functions to binary relations we define type vector transformations as follows.

\begin{definition}[Type Vector Transformation]
Let $R \subseteq \{1, \ldots, n\} \times \{1, \ldots, m\}$ be a left-total and right-total binary relation.
\begin{itemize}
\item $R(A_1, \ldots, A_n) := (\tau_1, \ldots, \tau_m)$ where $\tau_i = \{A_j \mid j \, R\, i\}$
\item $R(\sigma_1, \ldots, \sigma_n) := (\tau_1, \ldots, \tau_m)$ where $\tau_i = \bigcup \{\sigma_j \mid j \, R\, i\}$
\item $R(\{x_1 : \sigma_1, \ldots, x_l : \sigma_l\}) := \{x_1 : R(\sigma_1), \ldots, x_l : R(\sigma_l)\}$
\end{itemize}
\end{definition}

\begin{example}
For $R = \{(1, 1), (1, 3), (2, 1), (3, 2), (3, 3)\}$ we have \[R(a, b, c) = (\{a, b\}, \{c\}, \{a, c\})\]
\end{example}

Similar systems:
\begin{itemize}
\item The system $\lambda^{\mbox{CIL}}$ by Wells et al
  \cite{WellsDMT02} (see \cite{WellsH02} for a simplified version of
  the system) is a system in Church style with explicit type
  annotations in $\lambda$-biders where different derivations for the
  same subterm are managed by means of records. A record of types with
  labels from $I$ is derived here by a record of terms of
  corresponding labels from $I$.
\item The proof system ISL presented by Pimentel, Ronchi Della Rocca
  and Roversi \cite{PimentelRR12} features independent derivations in
  tuples led according to the same proof rules. Effectively this works
  like an intersection type system with vectors. However, the system
  does not have proof terms. A version of the proof system formulated
  in terms of a sequent calculus is presented in \cite{RoccaSSV10}.
\end{itemize}

Dissimilar systems:
\begin{itemize}
\item The system by Luigi Liquori and Simona Ronchi della Rocca
  \cite{LiquoriR07} is a system with explicit annotations at
  $\lambda$-binders. It introduces  terms in which variables in
  binders are annotadet with indices. Then these indices serve as
  pointers to binders in derivations, and the binders in derivations
  contain types.
\end{itemize}

\begin{definition}[Dimensional Restriction]
$\Gamma \vdash_k t : \bar{A}$ means that the length of vectors in some derivation of $\Gamma \vdash t : \bar{A}$ is at most $k$.
\end{definition}

\begin{theorem}
$\Gamma \vdash_{\textnormal{CDV}} t : A$ iff for some $k$ we have $\Gamma \vdash_k t : (A)$.
\end{theorem}

\begin{proposition}
Given $\Gamma$, $\bar{A}$, and $k$ it is decidable whether $\Gamma \vdash_k t : \bar{A}$ holds for some $t$.
\end{proposition}

\begin{proof}[(Proof Idea)]
In order to decide whether $\Gamma \vdash_k t : \bar{A}$ holds for some $t$, it suffices to consider $t$ in $\beta$-normal form.
For an \textsf{ASPACE} decision algorithm we need to limit the effective number of variables in type environments.
Assume $x : \bar{\sigma}$ occurs in some environment for an inhabitant in $\beta$-normal form.
Then each type $B$ which occurs in each set in each component of $\bar{\sigma}$ is a subformula of some type occurring in $\Gamma$ or $A$.
Therefore, there is finitely many distinct $\bar{\sigma}$.
By the pigeonhole principle, if there are more variables in a type environment, some must have identical types and thus a redundant copy can be removed.
Therefore, there are finitely many environements and types to consider throughout the cesition procedure.
\end{proof}

\begin{remark}
For fourth order matching $k$ is the product for the number of fragments of the right-hand sides.
However, intersection types in $\Gamma$ come from subject expansion of an intersection typing for an arbitrary candidate solution.
Therefore, not a sufficient restriction (at first glance).
However, one can try to relate types in $\Gamma$ to given simple types in the given fourth-order matching problem, possibly obtaining a finite bound of occurring types.
\end{remark}

\begin{definition}[Refinement]
An intersection type $A$ refines a simple type $\varphi$, written $A \prec \varphi$ if
\begin{itemize}
\item $A$ is a constant and $\varphi = \bullet$
\item $A = \sigma \to B$ and $\varphi = \varphi_1 \to \varphi_2$ and $B \prec \varphi_2$ and for all $A_1 \in \sigma$ we have $A_1 \prec \varphi_1$ 
\end{itemize}
\end{definition}

\begin{definition}[Shift]
We consider type atoms as words of natural numbers.
\begin{itemize}
\item ${\downarrow_i}w = wi$
\item ${\downarrow_i}(\{A_1, \ldots, A_n\} \to A) = (\{{\downarrow_i}A_1, \ldots, {\downarrow_i}A_n\} \to {\downarrow_i}A)$
\end{itemize}
\end{definition}

For example ${\downarrow_2}(\{12, 3\} \to \varepsilon) = \{122, 32\} \to 2$.

\begin{lemma}[Equality Characterization]\label{lem:eq_character}
If $r$ is in $\beta$-normal form and $\Phi \vdash_{\textnormal{STLC}} r : \varphi$ is a $\eta$-long derivation, then there exists $\Gamma$, $A$ such that
\begin{enumerate}
\item $\Gamma \prec \Phi$ and $A \prec \varphi$
\item $\Gamma \vdash r : A$
\item for all $t$ such that $\Phi \vdash_{\textnormal{STLC}} t : \varphi$ is an $\eta$-long derivation (not necessarily $\beta$-normal) and $\Gamma \vdash t : A$, then $t \twoheadrightarrow_\beta r$
\end{enumerate}
\end{lemma}

\begin{proof}[(Proof Idea)]
First we focus on $\beta$-normal forms.
The crucial step application.
Consider the example term $r = x\,r_1\,r_2$. By inversion we have $(x : \varphi_1 \to \varphi_2 \to \bullet) \in \Phi$ and $\Phi \vdash_{\textnormal{STLC}} r_i : \varphi_i$.
By induction hypothesis there are $\Gamma_1, A_1, \Gamma_2, A_2$ satisfying the above conditions.
We set $\Gamma = (x : {\downarrow_1} A_1 \to {\downarrow_2} A_2 \to \varepsilon) \cup {\downarrow_1}\Gamma_1 \cup {\downarrow_2}\Gamma_2$
and $A = \varepsilon$.
\end{proof}

\begin{lemma}[Disequality Characterization]\label{lem:neq_character}
If $r$ is in $\beta$-normal form and $\Phi \vdash_{\textnormal{STLC}} r : \varphi$ is a $\eta$-long derivation, then there exists $\Gamma$, $A$ such that
\begin{enumerate}
\item $\Gamma \prec \Phi$ and $A \prec \varphi$
\item $\Gamma \vdash r : A$
\item for all $t$ such that $\Phi \vdash_{\textnormal{STLC}} t : \varphi$ is an $\eta$-long derivation (not necessarily $\beta$-normal) and $\Gamma \vdash t : A$, then $t \not\twoheadrightarrow_\beta r$
\end{enumerate}
\end{lemma}

\begin{example}
Consider $\Phi = \{g : \bullet \to \bullet \to \bullet, y : \bullet\}$ and $r = g\,y\,y$.
Terms $t$ in $\beta$-normal form with an $\eta$-long derivation of $\Phi \vdash t : \bullet$ such that $t \neq r$ are
\begin{enumerate}
\item $y$\\
This can be characterized by $\{y : \{\varepsilon\}\} \vdash y : \varepsilon$
\item $g\,t'\,t''$ such that $t' \neq y$, which means $t = g\,t_1\,t_2$.\\
This can be characterized by $\{g : \{{\downarrow_1}\{\varepsilon\} \to \{\} \to \varepsilon\}, \{\} \to \{\} \to {\downarrow_1}\{\varepsilon\} \} \vdash g\,t'\,t'' : \varepsilon$
\item $g\,t''\,t'$ such that $t' \neq y$, which means $t = g\,t_1\,t_2$.\\
This can be characterized by $\{g : \{\{\} \to {\downarrow_2}\{\varepsilon\} \to \varepsilon\}, \{\} \to \{\} \to {\downarrow_2}\{\varepsilon\} \} \vdash g\,t''\,t' : \varepsilon$
\end{enumerate}
Putting it all together we can take $\Gamma = \{y : \{\varepsilon\}, g : \{{\downarrow_1}\{\varepsilon\} \to \{\} \to \varepsilon, \{\} \to \{\} \to {\downarrow_1}\{\varepsilon\}, \{\} \to {\downarrow_2}\{\varepsilon\} \to \varepsilon\}, \{\} \to \{\} \to {\downarrow_2}\{\varepsilon\}\}$ and $A = \varepsilon$ such that $\Gamma \vdash t : A$.
\end{example}

\begin{example}
Consider $\Phi = \{f : (\bullet \to \bullet) \to \bullet, g : \bullet \to \bullet \to \bullet, y : \bullet\}$ and $r = f\,(\lambda x.g\,x\,y)$.
This extends the previos example.
Terms $t$ in $\beta$-normal form with an $\eta$-long derivation of $\Phi \vdash t : \bullet$ are
\begin{enumerate}
\item $y$\\
This can be characterized by $\{y : \{\varepsilon\}\} \vdash y : \varepsilon$
\item $g\,t_1\,t_2$\\
This can be characterized by $\{g : \{\} \to \{\} \to \varepsilon \} \vdash g\,t_1\,t_2 : \varepsilon$
\item $f\,(\lambda x.t')$ such that $t' \neq g\,x\,y$\\
Here we have $\Phi, x : \bullet : g\,x\,y : \bullet$ and can derive $\Gamma'$, $A' = \varepsilon$ as characterization for any $\beta$-normal $\eta$-long typed term different from $g\,x\,y$.
Let $\Gamma'' = \Gamma' \setminus \{x\}$
Overall we can take $\Gamma = \Gamma'' \cup \{y : \{\varepsilon\}, g : \{\} \to \{\} \to \varepsilon, f : \Gamma'(x) \to \varepsilon\}$ and $A = \varepsilon$.
\end{enumerate}
\end{example}

\begin{lemma}
\label{lem:transform}
If $\Gamma \vdash t : \bar{A}$ and $R$ is right-unique, then $R(\Gamma) \vdash t : R(\bar{A})$.
\end{lemma}

\begin{lemma}[substitution lemma]
  ~\\
  Assume $\bar{A} = (A_1,\ldots,A_n)$ and $\bar{B} =
  (B_1,\ldots,B_m)$, and $\bar{\sigma} =
  (\sigma_1,\ldots,\sigma_m)$.
  If $\Gamma, x:\sigma_i\vdash t : B_i$ %
  for $i=1,\ldots,m$ and $R$ is such that $\sigma_i = \{A_j \mid j\, R\, i\}$
  and $\Delta\vdash u : \bar{A}$ %
  then $\Gamma\uplus R(\Delta) \vdash t[x:=u] : \bar{B}$.
  
\end{lemma}
\begin{proof}
  Induction over $t$.

  \begin{itemize}
  \item $t=y$
    \begin{itemize}
    \item $y=x$ -- due to $R$ we can extract from the derivation for
      $u$ all the necessary derivations for $B$'s.
    \item $y\not=x$
    \end{itemize}
  \item $t=vw$ -- we have in the last derivation rule a relation
    $R'$. For the derivation of $w$ we need to adapt $R$ to take into
    account $R'$. This should be $R;R'^{-1}$.
  \item $t=\lambda y.u$ -- congruence.
  \end{itemize}
\end{proof}

\section{Application to Fourth-order Matching}

\begin{remark}[Roadmap]\label{rem:road}~
\begin{enumerate}
\item Start with equations
\[
\begin{array}{lll}
X\,u_1^1\ldots u_1^n &=& r_1\\
\vdots&&\vdots\\
X\,u_m^1\ldots u_m^n &=& r_m
\end{array}
\]
\item Construct characteristic typings
$\Gamma_{[i]} \vdash r_i : \bar{A}_{[i]}$ for $i = 1, \ldots, m$
\item\label{rem:road:character}
By Lemma~\ref{lem:eq_character} there is a solution $\lambda x_1 \ldots x_n.t$ iff there is a $k$ such that for all $i \in \{1, \ldots, m\}$ we have \[\Gamma_{[i]} \vdash_k (\lambda x_1 \ldots x_n.t)\,u_i^1\ldots u_i^n : \bar{A}_{[i]}\]
\item By inversion this is equivalent to: there are some $R_1^1, \ldots, R_m^n$ and $\bar{B}_1^1, \ldots, \bar{B}_m^n$ such that for all $i \in \{1, \ldots, m\}$ we have
\[\Gamma_{[i]} \vdash_k (\lambda x_1 \ldots x_n.t) : R_i^1(\bar{B}_i^1) \Rightarrow \cdots \Rightarrow R_i^n(\bar{B}_i^n) \Rightarrow \bar{A}_{[i]}\]
\item In combination this is equivalent to: there are some  $R^1, \ldots, R^n$ and $\bar{B}^1, \ldots, \bar{B}^n$ such that for all $i \in \{1, \ldots, m\}$ we have
\[\Gamma, x_1 : \bar{B}^1, \ldots, x_n : \bar{B}^n \vdash_{mk} t : R^1(\bar{B}^1) \Rightarrow \cdots \Rightarrow R^n(\bar{B}^n) \Rightarrow \bar{A}\]
This is exactly inhabitation in dimension $mk$.
\end{enumerate}
\end{remark}

\begin{remark}[Key Step]
The key step in Remark~\ref{rem:road} is determining the dimension bound $k$ in Step \ref{rem:road:character}.
Ideas, how to establish this key step include:
\begin{itemize}
\item Bounded subject expansion in order $4$ starting from normal form $r_i$
\item Padowani-style argument with maximal number of assumptions
\item States in a run of a Krivine machine
\end{itemize}
\end{remark}

\begin{definition}
  Assume
  $\bar{A} =
  \sigma_1\Rightarrow\cdots\Rightarrow\sigma_n\Rightarrow\bar{B}$ is a
  type over constants $C$, where $\bar{B}$ are type constants,
  $\vdash_k t :\tau$ and $\vdash_k u :\tau$.
  \begin{displaymath}
    \begin{array}{lcp{200pt}}
      t \preceq^k_{\tau} u &  \mbox{ if and only if } &
    for each $u_1,\ldots,u_n$ such that $\vdash_k u_i:\sigma_i$ if
    $tu_1\ldots u_n\to_\beta \bar{B}_i$ then $uu_1\ldots u_n\to_\beta \bar{B}_i$
    \end{array}
  \end{displaymath}
  If $t \preceq^k_{\tau} u$ and $u \preceq^k_{\tau} t$ then $t \simeq^k_{\tau} u$.
  Abstraction class of $t$ with regard to $\simeq^k_{\tau}$ is written $[t]^k_\tau$.
\end{definition}


\begin{lemma}
  Assume
  $\bar{A} =
  \sigma_1\Rightarrow\cdots\Rightarrow\sigma_n\Rightarrow\bar{B}$ is a
  type over constants $C$, where $\bar{B}$ is a type constant and
  $\dim(\bar{B})=1$.  If $t\simeq^k_{\bar{A}} u$ and
  $tu_1\ldots u_n\to^*_\beta \bar{B}_1$ then
  $uu_1\ldots u_n\to^*_\beta \bar{B}_1$.
\end{lemma}

\begin{lemma}
  If there is a typing $\Gamma\vdash t:\bar{A}$ where $\Gamma,\bar{A}$
  use constants from a set $C$ and
  then there is a typing
  $\Gamma\vdash_k t:\bar{A}$ where
  $$
  k=\max\{ \fsize(C,r,a) \mid r = \rank(A), a=\arity(A)
    \mbox{ where } B\in\Types(\Gamma,\bar{A}) \}.
  $$
\end{lemma}
\begin{proof} (Sketch)
  The proof is by induction over derivation of $t$. For a subterm $uv$
  we may assume that the relation $R$ used in the relevant ($\Rightarrow E$)
  is right-unique as the number of types is lower than $k$ some coordinates
  are not used if dimension is greater than $k$. We can remove these coordinates
  by weakening.
\end{proof}

\begin{definition}
  Derivation $\vdash t : \bar{A}$ \emph{semantically agrees with constants
    $C$} if for each subterm $u$ of $t$ and its subderivation
  $x_1:\sigma_1,\ldots,x_n:\sigma_n\vdash u : \bar{A}$ where $\bar{A}$
  and its minimal decomposition

\section{Application to Fifth-order Matching}

\begin{remark}[Main Idea]\leavevmode
\begin{enumerate}
\item Reduce routing by main variables to constants (similar to unfolding) to bound the number of occurrences of main variables.
\item Use Dimension Bound Lemma~\ref{lem:fifth-dim-bound} to bound the dimension of a potential solution.
\item Use decidable inhabitation in bounded dimension to obtain the solution.
\end{enumerate}
\end{remark}

\begin{lemma}[Dimension Bound]\label{lem:fifth-dim-bound}
A bound on the number of occurrences of main variables $x_1, \ldots, x_n$ bounds the dimension of the solution term $\lambda x_1 \ldots x_n.t$.
\end{lemma}

\begin{proof}[Proof Idea]
In fifth order matching a main variable $x$ may have the type
\begin{align*}
&a_1 \to \\
&\big((a_2 \to a_3) \cap (a_4 \to a_5)\big) \to\\
&\Big(\big((a_6 \to a_7) \cap (a_8 \to a_9)\big) \to a_{10}\Big) \cap \Big(\big((a_{11} \to a_{12}) \cap (a_{13} \to a_{14})\big) \to a_{15}\Big) \to\\
&a_{16}
\end{align*}
So that the application $x\,v_1\,(\lambda z.v_2)\,(\lambda f.v_3)$ can introduce intersections.
Use of the introduces variables $z$ and $f$ deeper in the term do not introduce intersections becuase they have a simple domain at each occurrence.
Critically, $f$ cannot be assigned the type $(b_1 \cap b_2) \to b_2$ in a fifth-order matching scenario beucase it would require an argument that both occurs at position $b_1$ and $b_2$, which are distinct occurrences.
Overall, only applications with the main variable at head positions do require intersection introduction.
The dimension bound is $M^N$ where $N$ is the nuber of occurrences of main variables and $M$ is the maximal number of elements in an intersection. The number $M$ itself is bounded by the number of different intersection types of third order types refining the simple types in the original matching instance, and constants correspond to subterms on the right-hand sides.  
\end{proof}

\section{Fifth-order Matching by Typed Transformations}
\label{sec:fifth-typed}

This section makes step~1 of the Main Idea above precise.
The number of occurrences of main variables is bounded via a small-solution property.
All its transformations (garbage removal, pumping, unfolding) are justified by type derivations and Lemma~\ref{lem:eq_character}.
Decidability is reduced to a width bound (Lemma~\ref{lem:fifth-width}).
At present the width bound follows only from~\cite{stirling2009}.
Typed unfolding (Section~\ref{sec:fifth-unfold}) is the intended tool for a type-based proof of it.

\subsection{Setting}

\paragraph{Instances.}
Orders are counted with $\mathrm{ord}(\bullet) = 1$.
We consider equations $X\,u_i^1\ldots u_i^n = r_i$ ($1 \le i \le m$) with $X : \varphi_1 \to \cdots \to \varphi_n \to \bullet$ of order at most $5$.
All constants in $\Phi$ are first-order, so every $r_i$ is a first-order term.
Disequations are analogous via Lemma~\ref{lem:neq_character}.

\paragraph{Shape of solutions.}
Since $\mathrm{ord}(\varphi_j) \le 4$, a solution $\lambda x_1\ldots x_n.t$ in $\eta$-long $\beta$-normal form is generated by
\[
t ::= c\,t_1\ldots t_k \mid x_j\,v_1\ldots v_h \mid z\,t_1\ldots t_k
\qquad
v ::= t \mid \lambda z_1\ldots z_k.\,t .
\]
The \emph{introduced variables} $z$ have first-order type $\bullet$ or second-order type $\bullet^k \to \bullet$.
An occurrence of $x_j\,v_1\ldots v_h$ is a \emph{main node}.

\paragraph{Typings.}
By the correspondence of $\vdash_{\textnormal{CDV}}$ with the parallel system, we reason per equation in the set-based system with top-down environments:
\[
\frac{A \in \Gamma(x)}{\Gamma \vdash x : A}
\qquad
\frac{\Gamma, x : \sigma \vdash s : A}{\Gamma \vdash \lambda x.s : \sigma \to A}
\qquad
\frac{\Gamma \vdash s : \sigma \to A \qquad \Gamma \vdash u : B \text{ for all } B \in \sigma}{\Gamma \vdash s\,u : A}
\]
We write $\omega$ for $\emptyset$ and omit braces of singletons.
An occurrence $\nu$ in $t$ may be the subject of several judgements.
Its \emph{instances} are
\[
\Inst(\nu) = \{(i,\Gamma,A) \mid \text{the derivation for equation } i \text{ contains } \Gamma \vdash t|_\nu : A \text{ for } \nu\}.
\]
In the parallel system, instances are the coordinates of the judgement at $\nu$.

\paragraph{Positional characteristic typings.}
For first-order $r_i$, the characteristic environment of Lemma~\ref{lem:eq_character} is
\[
\Gamma_i(c) = \{p1 \to \cdots \to pk \to p \mid r_i|_p = c\,r'_1\ldots r'_k\},
\]
with atoms the positions of $r_i$ and target $\varepsilon$.
Write $q \sqsubseteq p$ if $p$ is a prefix of $q$, and let $d_i$ be the maximal length of a position in $r_i$.

\begin{definition}[Decreasing Type]
Let $\tgt(a) = a$ and $\tgt(\sigma \to A) = \tgt(A)$.
A type $\sigma \to A$ is \emph{decreasing} if $A$ is decreasing and every $B \in \sigma$ is decreasing with $\tgt(B) \sqsubseteq \tgt(A)$.
Atoms are decreasing.
A decreasing type is \emph{flat} if all its atoms are equal.
A derivation is decreasing if all types in its judgements are decreasing.
\end{definition}

For $x : \sigma_1 \to \cdots \to \sigma_h \to p$, this says the following.
Every argument type $C \in \sigma_l$ has target $q \sqsubseteq p$.
Every type $D$ of an introduced variable in a domain of $C$ has target below $q$.
Every atom in a domain of $D$ is below $\tgt(D)$.
Intuitively, larger subterms of $r_i$ are only built from smaller ones or passed on.

\begin{lemma}[Branch Monotonicity]\label{lem:fifth-branch}
In a decreasing derivation, targets weakly decrease from a judgement to all judgements in its subderivation.
They decrease strictly into the arguments of a constant.
Hence every branch of the derivation for equation $i$ has at most $d_i$ strict steps.
\end{lemma}

\begin{lemma}[Decreasing Characteristic Typings]\label{lem:fifth-decr}
If $s \twoheadrightarrow_\beta r_i$, then $\Gamma_i \vdash s : \varepsilon$ holds by a decreasing derivation.
\end{lemma}

Let $T_i^j = \{B \prec \varphi_j \mid B \text{ decreasing},\ \Gamma_i \vdash u_i^j : B\}$.
This set is finite and computable.

\begin{corollary}[Solutions as Typings]\label{cor:fifth-sol}
$\lambda \bar x.t$ is a solution iff $\Gamma_i, x_1 : T_i^1, \ldots, x_n : T_i^n \vdash t : \varepsilon$ for all $i$.
In that case the derivations can be chosen decreasing.
\end{corollary}

From now on we fix a solution together with decreasing derivations in which $\Gamma(x_j) = T_i^j$ in every instance.

\subsection{Typed Replacement}

\begin{lemma}[Replacement]\label{lem:fifth-repl}
Let $\nu$ be an occurrence of type $\bullet$ in $t$.
Let $s$ be $\eta$-long and $\beta$-normal, with free variables in scope at $\nu$.
If $\Gamma \vdash s : A$ holds by a decreasing derivation for all $(i,\Gamma,A) \in \Inst(\nu)$, then $\lambda \bar x.\,t[\nu := s]$ is a solution with decreasing derivations.
\end{lemma}

\begin{corollary}[Garbage]\label{cor:fifth-garbage}
If $\Inst(\nu) = \emptyset$, then $\nu$ may be replaced by any closed term of type $\bullet$.
\end{corollary}

\begin{corollary}[Pumping]\label{cor:fifth-pump}
Let $\nu_2$ lie strictly below $\nu_1$, both of type $\bullet$.
Let $\theta$ be an injective, type-preserving renaming of the introduced variables free in $t|_{\nu_2}$ to introduced variables in scope at $\nu_1$.
Suppose that for every $(i,\Gamma_1,A) \in \Inst(\nu_1)$ there is $(i,\Gamma_2,A) \in \Inst(\nu_2)$ with $\Gamma_2(y) = \Gamma_1(\theta y)$ for all such $y$.
Then $\lambda \bar x.\,t[\nu_1 := \theta(t|_{\nu_2})]$ is a smaller solution.
\end{corollary}

\begin{proof}
Main variables have the same assumptions $T_i^j$ in both environments.
Rename the derivation of $t|_{\nu_2}$ by $\theta$ and apply Lemma~\ref{lem:fifth-repl}.
\end{proof}

\subsection{Small Solutions from Bounded Width}

The \emph{width} of $\nu$ is the number of introduced variables free in $t|_\nu$.
Let $y_1, \ldots, y_s$ be these variables, ordered by the positions of their binders.
The \emph{signature} of $\nu$ is
\[
\Sig(\nu) = \bigl(\text{simple types of } y_1,\ldots,y_s;\ \{(i, \Gamma(y_1), \ldots, \Gamma(y_s), A) \mid (i,\Gamma,A) \in \Inst(\nu)\}\bigr).
\]
All types involved refine the simple types of the instance over the finitely many positions.
Hence, for width at most $W$, the set $\mathfrak{S}_W$ of possible signatures is finite and computable.

The following is the bounded width / dimensional bound property.
\begin{lemma}[Width]\label{lem:fifth-width}
There is a computable $W$ such that every solvable instance has a solution with decreasing derivations in which every occurrence of type $\bullet$ has width at most $W$.
\end{lemma}

\begin{theorem}\label{thm:fifth-small}
Assume Lemma~\ref{lem:fifth-width}.
Then every solvable instance has a solution in which each branch contains at most $|\mathfrak{S}_W| + 1$ occurrences of type $\bullet$.
In particular, the number of occurrences of main variables is bounded.
By Lemma~\ref{lem:fifth-dim-bound} the dimension is bounded, and solvability is decidable by inhabitation in bounded dimension.
\end{theorem}

\begin{remark}
Lemma~\ref{lem:fifth-width} currently follows only from Stirling's depth bound~\cite{stirling2009}: a solution of depth $D$ has width at most $D \cdot q$, where $q$ is the maximal arity.
The type-based contribution so far is the reduction from width to depth.
\end{remark}

\subsection{Typed Unfolding}
\label{sec:fifth-unfold}

Let $n = x_j\,v_1\ldots v_h$ be a main node with $v_l = \lambda z_1\ldots z_k.\,b$.
Let $\nu = z_g\,e_1\ldots e_{k'}$ be an occurrence in $b$ whose head is introduced by $v_l$.
The \emph{unfolding} of $\nu$ at $n$ is
\[
R = x_j\,v_1\ldots v_{l-1}\,(\lambda z'_1\ldots z'_k.\,z'_g\,e_1\ldots e_{k'})\,v_{l+1}\ldots v_h
\qquad (\bar z' \text{ fresh}).
\]
The replacement $\nu := R$ localises the head occurrence of $z_g$.
The arguments $\bar e$ may still mention $z_1, \ldots, z_k$, so unfolding is applied inside-out.

\paragraph{Anatomy.}
Every $(i,\Gamma_\nu,a_\nu) \in \Inst(\nu)$ lies in a unique enclosing instance $(i,\Gamma,a) \in \Inst(n)$.
In this enclosing instance:
\begin{itemize}
\item $x_j$ has a head type $B = \sigma_1 \to \cdots \to \sigma_h \to a \in T_i^j$;
\item $v_l$ has a type $C = \tau_1 \to \cdots \to \tau_k \to q \in \sigma_l$, and $\Gamma_\nu(z_g) = \tau_g$;
\item the head of $\nu$ has a type $D_\nu = \rho_1 \to \cdots \to \rho_{k'} \to a_\nu \in \tau_g$.
\end{itemize}
By Lemma~\ref{lem:fifth-branch}, $a_\nu \sqsubseteq q \sqsubseteq a$.
We distinguish three levels:
\begin{description}
\item[(L1)] $q \sqsubseteq a$, i.e.\ output produced by $u_i^j$ around its $l$-th parameter;
\item[(L2)] $a_\nu \sqsubseteq q$, i.e.\ output produced by $t$ between $v_l$ and $\nu$;
\item[(L3)] the relation of the domains of $D_\nu$ to $a_\nu$.
\end{description}
Level (L3) is the classification of the previous section: $D_\nu$ is non-contributing iff some source contains $a_\nu$.
The pair $(n,\nu)$ is \emph{flat} in the instance if $a_\nu = q = a$.

\begin{lemma}[Typed Unfolding]\label{lem:fifth-unfold}
Suppose that for every $(i,\Gamma_\nu,a_\nu) \in \Inst(\nu)$ there is $B^* = \sigma^*_1 \to \cdots \to \sigma^*_h \to a_\nu \in T_i^j$ such that the following hold:
\begin{itemize}
\item[(a)] $\Gamma_\nu \vdash v_{l'} : C'$ for all $l' \neq l$ and $C' \in \sigma^*_{l'}$;
\item[(b)] for every $C' = \tau'_1 \to \cdots \to \tau'_k \to q' \in \sigma^*_l$ there is $D' \in \tau'_g$ with $\tgt(D') = q'$ and $\Gamma_\nu \vdash e_m : E$ for all $m$ and all $E$ in the $m$-th domain of $D'$.
\end{itemize}
Then $\Gamma_\nu \vdash R : a_\nu$ in every instance, and $t[\nu := R]$ is a solution.
\end{lemma}

Level (L3) plays no role: $R$ replays what $u_i^j$ supplies for $z_g$, so contributing and fixed types of $z_g$ do not prevent unfolding.

\begin{corollary}[Canonical Unfolding]\label{cor:fifth-canon}
Suppose that in every instance of $\nu$ the pair $(n,\nu)$ is flat.
Suppose moreover \emph{uniformity}: condition~(b) holds for all $C' \in \sigma_l$ of the enclosing head type $B$.
Then Lemma~\ref{lem:fifth-unfold} applies with $B^* = B$.
This holds in particular if $B$ is flat and $\sigma_l = \{C\}$, taking $D' = D_\nu$.
\end{corollary}

In Stirling's example (see the long abstract), replacing $s_1$ by $x_1\,z_1\,(\lambda s_1 s_2.\,s_1)$ is a canonical unfolding: the head type $a \to (a \to \omega \to a) \to a$ is flat, and $\sigma_2$ is a singleton.

A strict step at (L2) only excludes the choice $B^* = B$.
For head calls the target can be shifted:

\begin{lemma}[Target Shift]\label{lem:fifth-shift}
Let $u_i^j = \lambda F_1\ldots F_h.\,F_l\,\pi_1\ldots\pi_k$.
Let $\mathcal{E}$ be a decreasing derivation of $\Gamma_i, \bar F : \bar N \vdash \pi_g : D_\nu$, where $N_{l'}$ is the set of types used for $F_{l'}$.
Put
\[
C^* = \omega \to \cdots \to D_\nu \to \cdots \to \omega \to a_\nu \quad (D_\nu \text{ at position } g),
\]
\[
B^* = N_1 \to \cdots \to (N_l \cup \{C^*\}) \to \cdots \to N_h \to a_\nu .
\]
Then $B^* \in T_i^j$.
Condition~(b) holds for $C^*$, and (a) and (b) reduce to $N_1, \ldots, N_h$.
\end{lemma}

\begin{proof}
The body of $u_i^j$ types with $F_l : C^*$ and $\pi_g$ typed by $\mathcal{E}$.
Types in $N_{l'}$ have targets $\sqsubseteq a_\nu$ by Lemma~\ref{lem:fifth-branch} applied to $\mathcal{E}$.
\end{proof}

\begin{example}
Let $u = \lambda F.\,F(\lambda y.\,F(\lambda y'.\,y))$, $r = g\,(g\,a\,c)\,c$ and $t = x\,(\lambda z.\,g\,(z\,a)\,c)$.
Then $x : \{C_1, C_2\} \to \varepsilon$ with $C_1 = (11 \to 1) \to \varepsilon$ and $C_2 = (\omega \to 11) \to 1$.
The two instances of $\nu = z\,a$ have types $1$ and $11$, so (L2) is strict in both.
In Lemma~\ref{lem:fifth-shift} we have $N_1 = \{C_2\}$, and (b) fails for $C_2$.
Accordingly, $t[\nu := x(\lambda z'.\,z'\,a)]\,u \twoheadrightarrow_\beta g\,a\,c \neq r$.
\end{example}

\paragraph{Nested uses of continuations.}
The derivations of Lemma~\ref{lem:fifth-decr} are \emph{tight}: every type assumed for a $\lambda$-bound variable is used by an axiom.
Tightness is preserved by the replacements below.

\begin{definition}[Spine]
Let $u_i^j = \lambda F_1\ldots F_h.\,b$, and let $\mathcal{U}$ be a derivation of $\Gamma_i \vdash u_i^j : B$.
A \emph{spine} of length $s$ in $\mathcal{U}$ is a sequence of calls
\[
b = F_{l_1}\,\bar\pi^1,
\qquad
\pi^m_{g_m} = \lambda \bar y^m.\,F_{l_{m+1}}\,\bar\pi^{m+1}\quad (1 \le m < s),
\]
together with the types $F_{l_m} : C^m$ and $\pi^m_{g_m} : D^m \in \tau_{g_m}(C^m)$ used in $\mathcal{U}$.
Here $\tau_g(C)$ denotes the $g$-th domain of $C$.
The spine \emph{ends} in the axiom $F_{l_s} : C^s$.
\end{definition}

A spine contains no constant of $u_i^j$.
The spine of length $1$ is the head call of Lemma~\ref{lem:fifth-shift}.

\paragraph{Setting.}
Fix the main node $n = x_j\,v_1\ldots v_h$ and the occurrence $\nu = z_g\,\bar e$ in the body of $v_l$.
Fix an instance $(i,\Gamma_\nu,a_\nu) \in \Inst(\nu)$ with enclosing head type $B$, with $v_l : C$ and $z_g : D_\nu$.
Assume that the derivation $\mathcal{U}$ of $u_i^j : B$ contains a spine ending in an axiom $F_l : C$, i.e.\ $l_s = l$ and $C^s = C$.
For $m < s$ we have $D^m \in \tau_{g_m}(C^m)$.
By tightness, the derivation of $v_{l_m} : C^m$ then contains an occurrence $\nu_m = z_{g_m}\,\bar e^m$ whose head has type $D^m$.
Put $\nu_s = \nu$.
We require:
\begin{itemize}
\item[(S1)] \emph{consistency}: if $l_m = l_{m'}$ then $\nu_m = \nu_{m'}$;
\item[(S2)] \emph{scope}: for $m < s$, all free variables of $\bar e^m$ are bound above $n$.
\end{itemize}
Define the \emph{skeleton re-call}
\[
R_S = x_j\,\Lambda_1\ldots\Lambda_h,
\qquad
\Lambda_{l'} =
\begin{cases}
\lambda \bar z'.\,z'_{g_m}\,\bar e^m & \text{if } l' = l_m \text{ for some } m \le s,\\
v_{l'} & \text{otherwise.}
\end{cases}
\]
By (S1), $R_S$ is well defined.
If the spine uses only slot $l$, then $R_S$ is the term $R$ of Lemma~\ref{lem:fifth-unfold}.

\paragraph{Pruned and retargeted type.}
Let $\mathcal{E}$ be the subderivation of $\pi^s_g : D_\nu$ in $\mathcal{U}$ at the final axiom.
It exists because $D_\nu \in \tau_g(C)$.
For $m < s$, let $\rho^{*m}$ be the types assumed for $\bar y^m$ that are used in $\mathcal{E}$.
For $1 \le l' \le h$, let $N_{l'}$ be the types of $F_{l'}$ used in $\mathcal{E}$.
Put
\[
\begin{array}{l}
D^{*m} = \rho^{*m} \to a_\nu,
\qquad
C^{*m} = \omega \to \cdots \to D^{*m} \to \cdots \to \omega \to a_\nu \quad (m < s),\\[1ex]
C^{*s} = \omega \to \cdots \to D_\nu \to \cdots \to \omega \to a_\nu,\\[1ex]
B^* = \sigma^*_1 \to \cdots \to \sigma^*_h \to a_\nu
\quad\text{with}\quad
\sigma^*_{l'} = N_{l'} \cup \{C^{*m} \mid l_m = l'\}.
\end{array}
\]
In $C^{*m}$ the non-$\omega$ domain is at position $g_m$, and in $C^{*s}$ it is at position $g$.

\begin{lemma}[Spine Shift]\label{lem:fifth-spine}
In the setting above:
\begin{enumerate}
\item $\Gamma_i \vdash u_i^j : B^*$ and $B^* \in T_i^j$.
\item If $\Gamma_\nu \vdash \Lambda_{l'} : C'$ for all $l'$ and all $C' \in N_{l'}$, then $\Gamma_\nu \vdash R_S : a_\nu$.
\end{enumerate}
\end{lemma}

\begin{proof}
(1) Type the spine bottom-up with all targets equal to $a_\nu$.
The call $F_l\,\bar\pi^s$ has type $a_\nu$ by $F_l : C^{*s}$, with $\pi^s_g$ typed by $\mathcal{E}$ and all other arguments typed by $\omega$.
Then $\pi^m_{g_m} : D^{*m}$ by $(\to\mathrm{I})$ with $\bar y^m : \rho^{*m}$, and $F_{l_m}\,\bar\pi^m : a_\nu$ by $F_{l_m} : C^{*m}$.
The spine targets are all $a_\nu$.
Since $\mathcal{E}$ is decreasing with target $a_\nu$, all types in $N_{l'}$ and $\rho^{*m}$ have targets $\sqsubseteq a_\nu$ by Lemma~\ref{lem:fifth-branch}.
Hence $B^*$ is decreasing.

(2) Take $C^{*m}$ with $m < s$.
We need $\Gamma_\nu \vdash \bar e^m : \rho^{*m}$.
All axioms for $\bar y^m$ in $\mathcal{E}$ lie inside the derivation of $\pi^m_{g_m} : D^m$, so $\rho^{*m} \subseteq \dom(D^m)$.
The derivation at $\nu_m$ gives $\Gamma_{\nu_m} \vdash \bar e^m : \dom(D^m)$.
Both $\Gamma_{\nu_m}$ and $\Gamma_\nu$ extend the environment of the enclosing instance of $n$, so by (S2) they agree on the free variables of $\bar e^m$.

Take $C^{*s}$.
Here $z'_g : D_\nu$, and $\Gamma_\nu \vdash \bar e : \dom(D_\nu)$ holds by the derivation at $\nu$.

Finally $x_j : B^* \in T_i^j = \Gamma_\nu(x_j)$, so $(\to\mathrm{E})$ gives $\Gamma_\nu \vdash R_S : a_\nu$.
\end{proof}

\begin{corollary}\label{cor:fifth-spine}
Suppose every instance of $\nu$ satisfies the hypotheses of Lemma~\ref{lem:fifth-spine} for some spine, and all resulting skeleton re-calls $R_S$ coincide.
Then $t[\nu := R_S]$ is a solution by Lemma~\ref{lem:fifth-repl}.
\end{corollary}

\begin{remark}
\leavevmode
\begin{itemize}
\item \emph{Only (L1) matters on the $u$-side.}
Retargeting removes every step $\tgt(D^m) \sqsubset \tgt(C^m)$ along the spine, i.e.\ output produced by $t$ between a slot and $\nu_m$.
The only restriction on $u_i^j$ is that no constant lies on the spine.
\item \emph{Failure of (S1).}
A slot is entered at two steps through different occurrences, which means $x_j$ uses one continuation in two coordinates via different introduced variables.
This is a global switch, i.e.\ obligation~(O2).
\item \emph{Failure of (S2).}
Either the step arguments mention variables bound in $t$ between the slot and $\nu_m$, or they mention the slot's own variables.
The latter case, exits into arguments, corresponds to Stirling's composite unfoldings.
It is handled by a closure of the construction:
\begin{itemize}
\item rename the slot variables in $\bar e^m$ to $\bar z'$;
\item add to $C^{*m}$ their types used in the typing of $\bar e^m$;
\item add to $\mathcal{E}$ the corresponding subderivations of $\bar\pi^m$ from $\mathcal{U}$.
\end{itemize}
All added subderivations lie inside the derivation of $\pi^m_{g_m} : D^m$, so $\rho^{*m} \subseteq \dom(D^m)$ still holds.
\end{itemize}
\end{remark}

\begin{example}
Consider the non-flat example with $u = \lambda F.\,F(\lambda y.\,F(\lambda y'.\,y))$.
For the nested instance of $\nu = z\,a$ (with $a_\nu = 11$), the spine has length $2$ and $\nu_1 = \nu_2 = \nu$.
The final polynomial is $\lambda y'.\,y : \omega \to 11$, so $\rho^{*1} = 11$.
Hence
\[
B^* = \{(11 \to 11) \to 11,\ (\omega \to 11) \to 11\} \to 11,
\]
and $x\,(\lambda z'.\,z'\,a) : 11$.
The top instance (spine of length $1$) fails, as shown before, so $\nu$ is not unfolded.
This agrees with $t[\nu := x(\lambda z'.z'a)]\,u \twoheadrightarrow_\beta g\,a\,c$.
With $r = a$, both instances succeed.
\end{example}

\begin{remark}[On Lemma~\ref{lem:fifth-dim-bound}]
With positional atoms, applications of introduced variables can also require intersections.
For $r = g\,a\,a$, $u = \lambda F.\,F(\lambda y.\,g\,y\,y)$ and $t = x\,(\lambda z.\,z\,a)$, we get $z : \{1,2\} \to \varepsilon$ and $a : \{1,2\}$.
Such intersections consist of positions of a single right-hand side.
They should therefore only add a factor $|\Pos(r_i)|$ per coordinate.
The proof idea of Lemma~\ref{lem:fifth-dim-bound} needs to be amended accordingly.
\end{remark}

\subsection{Simplifications}
\label{sec:fifth-simpl}

\begin{remark}[Positions]
With ${\downarrow_i}w = wi$, atoms are paths read from the node to the root.
Hence $q \sqsubseteq p$ means that $p$ is a \emph{suffix} of $q$.
\end{remark}

Instances become pairs $(\Gamma, A)$.
The equation of an instance is the last symbol of $\tgt(A)$.
The spine data of $B \in T^j$ are taken from $u_i^j$, where $i$ is the last symbol of $\tgt(B)$.
Combining the arguments $u_i^1, \ldots, u_i^n$ into $\lambda p.\,p\,u_i^1 \ldots u_i^n$ is no substitute: the new main variable has order up to $6$.

\begin{lemma}[Projection Elimination]\label{lem:fifth-proj}
Let $\nu = z\,e_1\ldots e_{k'}$.
Suppose that in every instance $(\Gamma_\nu, a_\nu)$ of $\nu$ the head type of $z$ contains $a_\nu$ in its $k$-th domain, for one fixed $k$.
Then $t[\nu := e_k]$ is a solution.
\end{lemma}

\begin{proof}
The derivation of $\nu$ contains $\Gamma_\nu \vdash e_k : a_\nu$.
Apply Lemma~\ref{lem:fifth-repl}.
\end{proof}

\begin{lemma}[Routing Elimination]\label{lem:fifth-route}
Let $n = x_j\,v_1\ldots v_h$ with $v_l = \lambda \bar z.\,b$ and $\bar z \cap \FV(b) = \emptyset$.
Suppose that in every instance $(\Gamma, a)$ of $n$ the head type has some $C \in \sigma_l$ with $\tgt(C) = a$.
Then $t[n := b]$ is a solution.
\end{lemma}

\begin{proof}
From $\Gamma, \bar z : \bar\tau \vdash b : a$ and $\bar z \cap \FV(b) = \emptyset$ we get $\Gamma \vdash b : a$.
Apply Lemma~\ref{lem:fifth-repl}.
\end{proof}

\begin{definition}[Exit]\label{def:fifth-exit}
Consider an instance of $\nu$ with a spine as in Lemma~\ref{lem:fifth-spine}.
The instance is an \emph{exit} if $\pi^s_g = \lambda \bar y^s.\,y$, where $y$ is the $k$-th parameter of $\pi^m_{g_m}$ for some $m \le s$.
Its \emph{exit term} $e^*$ is the $k$-th argument of $\nu_m$.
If the body of $\pi^s_g$ is headed by a constant, the instance is an \emph{output}; if it is headed by some $F$, it is a \emph{re-entry}.
\end{definition}

\begin{lemma}[Exit Unfolding]\label{lem:fifth-exit}
Suppose every instance of $\nu$ is an exit, and across all instances and spine steps:
\begin{enumerate}
\item[(i)] each slot $l'$ is entered with a single index $g(l')$;
\item[(ii)] each pair $(l', k)$ has at most one exit term $e^*(l',k)$;
\item[(iii)] the free variables of each $e^*(l',k)$ are bound above $n$, unless $e^*(l',k)$ is an argument of $\nu$ exited at the final step.
\end{enumerate}
Let $R = x_j\,\Lambda_1\ldots\Lambda_h$ with
\[
\Lambda_{l'} = \lambda \bar z'.\,z'_{g(l')}\,d_1\ldots d_{k'},
\qquad
d_k =
\begin{cases}
e^*(l',k) & \text{if defined,}\\
\text{a closed dummy} & \text{otherwise,}
\end{cases}
\]
and let $\Lambda_{l'}$ be a closed dummy for slots not on any spine.
Then $t[\nu := R]$ is a solution, and $\FV(R) \subseteq \{x_j\} \cup \bigcup \FV(e^*)$.
\end{lemma}

\begin{proof}
In Lemma~\ref{lem:fifth-spine}, the derivation $\mathcal{E}$ is the single axiom $y : a_\nu$.
Hence $N = \emptyset$, $\rho^{*m'} = \omega$ for $m' \neq m$, and $\rho^{*m}$ is $a_\nu$ at position $k$.
For $m' \neq m$, the type $C^{*m'}$ imposes nothing on the arguments of $z'_{g_{m'}}$.
The type $C^{*m}$ requires $\Gamma_\nu \vdash e^* : a_\nu$, which holds as in Lemma~\ref{lem:fifth-spine}(2).
Slots with $\sigma^*_{l'} = \emptyset$ may hold closed dummies.
\end{proof}

\begin{remark}[Which occurrences to unfold]
\leavevmode
\begin{itemize}
\item \emph{One projection index in all instances:} Lemma~\ref{lem:fifth-proj}; no re-call is needed.
This also covers delayed switches, i.e.\ projections realised by re-entries.
\item \emph{All instances exits:} Lemma~\ref{lem:fifth-exit}.
This covers global switches (at least two indices) whose polynomials are syntactic projections.
\item \emph{Some instance an output:} do not unfold.
Nested outputs are strict steps, so there are at most $d$ of them per branch and instance (Lemma~\ref{lem:fifth-branch}).
\item \emph{Some instance a re-entry:} $\nu$ is an intermediate step of the spines of deeper exits.
Unfolding $\nu$ itself requires condition (b) for $N$ in Lemma~\ref{lem:fifth-spine}.
\end{itemize}
Own exits have non-contributing head types.
Exits to enclosing parameters have fixed head types, so a fixed type need not produce output.
After exhaustive application, a main node whose binders no longer occur in its continuation is removed by Lemma~\ref{lem:fifth-route}.
This fails only if $u^j$ selects different continuations in different instances, which is a switch on the level of the main variable.
\end{remark}

\subsection{Regions, Heads and Links based on Checkers Calculus}
\label{sec:fifth-regions}

We paint $t$ black and each $u^j$ white.

\begin{definition}[Regions]
A \emph{region} is a maximal subterm of type $\bullet$ of $t$ or of some $u^j$ that contains no abstraction and does not enter arguments of variables.
Arguments of constants belong to the region of the constant.
The regions are:
\begin{itemize}
\item \emph{black}: the body of $t$; the body $b$ of each argument $\lambda\bar z.b$ of a main node; each (ground) argument of an introduced variable;
\item \emph{white}: the body of each $u^j$; the body $e$ of each polynomial $\lambda\bar y.e$ passed to a call $F\,\bar\pi$ (ground arguments of $F$ are polynomials without parameters).
\end{itemize}
The \emph{head} of a region is its root symbol.
Its \emph{kind} is:
\begin{itemize}
\item \emph{output} if the head is a constant;
\item \emph{call} if the head is a variable of positive order ($x_j$ or a second-order $z$ in black regions; $F$ in white regions);
\item \emph{return} if the head is a ground variable (a ground $z$ in black regions; a parameter $y$ in white regions).
\end{itemize}
A return is \emph{own} if the head is bound by the abstraction directly above the region, and \emph{outer} otherwise.
\end{definition}

Calls and returns always cross colours.
Calls enter the other colour, and returns exit into it.

\begin{lemma}[Head Axiom]\label{lem:fifth-head}
In a decreasing derivation, consider a judgement of a region with target $a$.
The axiom of its head has target $a$.
Every other axiom of the region has a target strictly below $a$.
Hence the head, and therefore the kind of the region, is the unique axiom of the region with target $a$.
\end{lemma}

\begin{proof}
Function premises preserve the target.
All other symbols of a region lie in arguments of constants, which have strictly smaller targets.
Arguments of variables form separate regions.
\end{proof}

\paragraph{Links.}
Axioms of variables are linked to the typings of the terms substituted for them:
\begin{itemize}
\item a call $x_j : B$ is linked to a derivation $\mathcal{U}_B$ of $u^j : B$;
\item a call $F_l : C$ in $\mathcal{U}_B$ is linked to the derivation of the argument $v_l : C$ at the main node;
\item a call $z : D$ is linked to the derivation of the substituted polynomial at $D$, at a linked $F$-call;
\item a return is linked to the typing of the corresponding argument.
\end{itemize}
In set-based systems a use may be linked to several call sites of the same type, and any one may be chosen.
In multi types, links are bijections between multiset elements (up to equal types).

\begin{table}[h]
\centering
\begin{tabular}{lll}
Head of the polynomial region at $z : D$ & Head axiom (target $a = \tgt(D)$) & Type class of $D$\\ \hline
output & $c : \ldots \to a$ & contributing or fixed\\
call (re-entry) & $F : C'$ with $\tgt(C') = a$ & any\\
own return $y_k$ & $y_k : a$ & non-contributing ($a$ in the $k$-th domain)\\
outer return $y'$ & $y' : a$ & fixed
\end{tabular}
\end{table}

\begin{definition}[Routed Path]
A white region is \emph{routed} if its head is a call.
Consider an instance of $\nu = z_g\,\bar e$, where $z_g$ is bound at the main node $n$ and $n$ calls $x_j : B$.
A \emph{routed path} for the instance is a sequence $W_1, \ldots, W_s$ of routed white region judgements in $\mathcal{U}_B$ such that:
\begin{itemize}
\item $W_1$ is the body of $u^j$;
\item the head of $W_m$ is a call $F_{l_m} : C^m$;
\item $W_{m+1}$ is the body of the argument $\pi^m_{g_m}$ of that call, typed at some $D^m \in \tau_{g_m}(C^m)$;
\item the head $F_l : C$ of $W_s$ is linked to the continuation derivation that contains the instance of $\nu$.
\end{itemize}
The \emph{final derivation} $\mathcal{E}$ is the derivation of $\pi^s_g : D_\nu$ at the head call of $W_s$.
\end{definition}

By Lemma~\ref{lem:fifth-head}, $W_m$ is routed iff it contains an axiom $F : C'$ with $\tgt(C') = \tgt(W_m)$.
Hence routed paths are exactly the spines of Definition~\ref{def:fifth-exit}, characterised by targets alone.
For $m < s$, relevance yields a linked black use $\nu_m$ of $z_{g_m}$ at $D^m$.
Black regions between the root of a continuation and $\nu_m$ are unconstrained: $R$ skips them.

\begin{lemma}[Call-free Unfolding]\label{lem:fifth-callfree}
Suppose every instance of $\nu$ has a routed path whose final derivation $\mathcal{E}$ contains no call axiom.
Suppose (S1) holds, and the following scope condition:
\begin{itemize}
\item[(S2')] for every return $y : b$ in $\mathcal{E}$ where $y$ is the $k$-th parameter of $\pi^m_{g_m}$ with $m < s$, the free variables of the $k$-th argument of $\nu_m$ are bound above $n$.
\end{itemize}
Let $R_S$ be the skeleton re-call of Lemma~\ref{lem:fifth-spine}.
In $R_S$, arguments at parameter positions that are not returned in $\mathcal{E}$ may be replaced by closed dummies.
Then $t[\nu := R_S]$ is a solution.
\end{lemma}

\begin{proof}
Since $\mathcal{E}$ contains no call, we have $N = \emptyset$ in Lemma~\ref{lem:fifth-spine}.
The set $\rho^{*m}$ consists of the types of the returns of parameters of $\pi^m_{g_m}$ in $\mathcal{E}$.
Their arguments are typed as in Lemma~\ref{lem:fifth-spine}(2).
Own returns (step $s$) are typed by the derivation of $\nu$.
\end{proof}

\begin{remark}
Lemma~\ref{lem:fifth-exit} is the case where $\mathcal{E}$ is a single return.
Outputs whose constant arguments contain no calls are now also unfolded.
If $\mathcal{E}$ contains a call, i.e.\ a re-entry or an output with nested calls, then $\nu$ is not the end of its routed path.
The path then continues into the linked continuation, and the call-free end of that path is unfolded instead.
With constants typed by silent arrows, ``$\mathcal{E}$ contains no call'' means that $\mathcal{E}$ has interaction index~$0$ in the checkers system.
\end{remark}

\section{Non-trivial Example}

\begin{example}[Unfolding needs a skeleton]\label{ex:fifth-skeleton}
Let $\Phi = \{g, f : \bullet \to \bullet,\ a, b : \bullet\}$, and let
\[
X : \big(((\bullet\to\bullet)\to\bullet) \to ((\bullet\to\bullet)\to\bullet) \to \bullet\big) \to (\bullet \to \bullet) \to \bullet
\]
(order $5$).
Consider the two equations
\[
X\,u_1\,w = g\,(f\,a), \qquad X\,u_2\,w = g\,(f\,b),
\]
with
\[
u_1 = \lambda F_1 F_2.\,F_1\,(\lambda y.\,F_2\,(\lambda y'.\,y)),
\qquad
u_2 = \lambda F_1 F_2.\,F_1\,(\lambda y.\,F_2\,(\lambda y'.\,y')),
\qquad
w = \lambda h.\,f\,h .
\]
A solution is
\[
t = \lambda x_1 x_2.\; \underbrace{x_1\,(\lambda z_1.\,g\,(z_1\,a))\,(\lambda z_2.\,x_2\,(z_2\,b))}_{n} .
\]
We have $t\,u_1\,w \twoheadrightarrow g\,((\lambda y.\,x_2((\lambda y'.y)\,b))\,a) \twoheadrightarrow g\,(f\,a)$, and  $t\,u_2\,w \twoheadrightarrow g\,(f\,b)$.

The main node $n$ is unproductive, since $u_1$ and $u_2$ contain no constants.
It binds $z_1$ and $z_2$.
The occurrence $o = z_2\,b$ lies below the productive main node $x_2(\cdot)$, so it is far.

\paragraph{Typings.}
The characteristic environments are $\Gamma_1 = \{g : 1 \to \varepsilon,\ f : 11 \to 1,\ a : 11\}$ and $\Gamma_2 = \{g : 1 \to \varepsilon,\ f : 11 \to 1,\ b : 11\}$.
The head types of $n$ are
\[
B_1 = C_1 \to C_2 \to \varepsilon,
\quad C_1 = (11 \to 1) \to \varepsilon,
\quad C_2 = (\omega \to 11) \to 1,
\]
\[
B_2 = C'_1 \to C'_2 \to \varepsilon,
\quad C'_1 = (\omega \to 1) \to \varepsilon,
\quad C'_2 = (11 \to 11) \to 1 .
\]
Slot~$1$ is entered by the head call.
Slot~$2$ is entered by a re-entry from the polynomial $\lambda y.\,F_2(\ldots)$ bound to $z_1$, so its target is $1 \neq \varepsilon$.
The occurrence $o$ has two instances, both with target $11$:
\begin{itemize}
\item in equation~1, $z_2 : \omega \to 11$ is an \emph{outer} return of $y$, i.e.\ of the argument $a$ of the use $\nu_1 = z_1\,a$;
\item in equation~2, $z_2 : 11 \to 11$ is an \emph{own} return of $b$.
\end{itemize}

\paragraph{What fails.}
\begin{itemize}
\item \emph{Projection and Outer Return Elimination.}
$o := b$ fails in equation~1, and $o := a$ fails in equation~2.
\item \emph{Canonical unfolding.}
It requires $B^* = B_i$ with target $\varepsilon \ne 11$.
Target shift at the head call is also inapplicable, since the head of $u_i$ is $F_1$, not $F_2$.
\item \emph{Keeping the original slot~1.}
The re-call $x_1\,(\lambda z_1.\,g\,(z_1\,a))\,(\lambda z'_2.\,z'_2\,b)$ evaluates to $g\,a$, respectively $g\,b$, instead of $a$, respectively $b$.
In types, $\lambda z_1.\,g(z_1\,a)$ would need a type with target $11$, but $g$ is typed only at $\varepsilon$.
\end{itemize}

\paragraph{The skeleton re-call.}
The routed path has length~$2$: the head call $F_1$, then the head $F_2$ of $\lambda y.\,F_2(\ldots)$.
Its linked use is $\nu_1 = z_1\,a$ with exit term $a$.
Lemma~\ref{lem:fifth-callfree} yields
\[
R_S = x_1\,(\lambda z'_1.\,z'_1\,a)\,(\lambda z'_2.\,z'_2\,b),
\]
typed in the two instances by
\[
B^*_1 = ((11 \to 11) \to 11) \to ((\omega \to 11) \to 11) \to 11
\]
\[
B^*_2 = ((\omega \to 11) \to 11) \to ((11 \to 11) \to 11) \to 11
\]
Both are derivable for $u_1$, respectively $u_2$.
\begin{itemize}
\item In equation~1, $z'_1 : 11 \to 11$ uses $a : 11$, and $b$ is untyped.
\item In equation~2, $a$ is untyped, and $z'_2 : 11 \to 11$ uses $b : 11$.
\end{itemize}
Indeed $u_1\,(\lambda z'_1.z'_1\,a)\,(\lambda z'_2.z'_2\,b) \twoheadrightarrow a$ and $u_2\,(\ldots) \twoheadrightarrow b$.
The result is
\[
t' = \lambda x_1 x_2.\; x_1\,(\lambda z_1.\,g\,(z_1\,a))\,\big(\lambda z_2.\,x_2\,(x_1\,(\lambda z'_1.\,z'_1\,a)\,(\lambda z'_2.\,z'_2\,b))\big),
\]
in which $z_2$ no longer occurs.

\paragraph{The required features.}
The occurrence lives in slot~$2$, yet the re-call must replace slot~$1$ by a skeleton.
This skeleton drops the black output $g$ and keeps only the exit term $a$ of $\nu_1$.
The type of $z_2$ switches between a fixed type (outer return) and a non-contributing type (own return).
Hence global switches must also cover outer returns.
\end{example}

\begin{remark}[Reading Example~\ref{ex:fifth-skeleton} off the colored derivation]
Consider the derivations of $(\lambda x_1x_2.t)\,u_i\,w$.
Uses are black axioms, and each is linked to a white derivation.
The head axiom of a region is the axiom carrying its target (Lemma~\ref{lem:fifth-head}).
\begin{center}
\begin{tabular}{llllll}
eq. & use & type at the use & head of linked white derivation & linked $\kappa \neq 0$ & kind\\ \hline
1 & $x_1$ & $B_1$ & $F_1 : C_1$ (target $\varepsilon$) & entry $2$, ret $1$ & routing call\\
1 & $x_2$ & $[11] \to 1$ & $f$ (target $1$) & prod $1$, ret $1$ & productive call\\
1 & $z_1$ & $[11] \to 1$ & $F_2 : C_2$ (target $1$) & entry $1$, ret $1$ & re-entry\\
1 & $z_2$ & $[\,] \to 11$ & $y : 11$, $y$ bound by $\lambda y$ & ret $1$ & outer return\\ \hline
2 & $x_1$ & $B_2$ & $F_1 : C'_1$ (target $\varepsilon$) & entry $2$, ret $1$ & routing call\\
2 & $x_2$ & $[11] \to 1$ & $f$ (target $1$) & prod $1$, ret $1$ & productive call\\
2 & $z_1$ & $[\,] \to 1$ & $F_2 : C'_2$ (target $1$) & entry $1$, ret $1$ & re-entry\\
2 & $z_2$ & $[11] \to 11$ & $y' : 11$, $y'$ bound by $\lambda y'$ & ret $1$ & own return
\end{tabular}
\end{center}

\paragraph{Productions.}
In both equations, position $\varepsilon$ is produced by the black $g$ and position $1$ by the white $f$ of $w$.
Position $11$ is produced by the black $a$ (argument of $z_1$) in equation~1, and by the black $b$ (argument of $z_2$) in equation~2.
This gives $\kappa_{\mathrm{prod}} = 3 = |\Pos(r_i)|$.
The call of $x_1$ has $\kappa_{\mathrm{prod}} = 0$, so $n$ only routes.

\paragraph{Unfolding.}
The linked derivation of each instance of $o = z_2\,b$ consists of a single return, so $o$ is returning.
Following the links backwards gives the routed path:
\begin{itemize}
\item the continuation of slot~2 is linked to the axiom of $F_2$;
\item this axiom is the head of the region of the polynomial linked to the use $\nu_1$ of $z_1$;
\item that polynomial is an argument of the axiom of $F_1$, which is the head of the body region of $u_i$.
\end{itemize}
Hence the path enters slots $(1,2)$ via the variables $(z_1, z_2)$.
The return determines the exit term:
\begin{itemize}
\item in equation~1, $y$ is the parameter of step~1, so the exit term is the argument $a$ of $\nu_1$;
\item in equation~2, $y'$ is the own parameter, so the exit term is the argument $b$ of $o$.
\end{itemize}
Consistency (S1) and scope (S2') hold.
Pruning the linked white derivation to the path and the final return, and retargeting the path to $11$, yields $B^*_1$ and $B^*_2$ together with their derivations.
Hence $R_S = x_1\,(\lambda z'_1.\,z'_1\,a)\,(\lambda z'_2.\,z'_2\,b)$.
Its index adds $1$ call, $2$ entries and $1$ use per instance, in accordance with the table of effects.

\paragraph{Caveats.}
\begin{itemize}
\item The types of introduced variables do not determine kinds.
$[11] \to 1$ has the contributing shape but is a re-entry.
$[\,] \to 11$ and $[\,] \to 1$ have the fixed shape but are an outer return and a re-entry.
\item Kinds belong to the white derivation linked to a use.
In an inhabitation search over $T^j$, a derivation of $u_i^j$ must therefore be fixed for each type used.
\item The replacement is a term: its exit terms are copied from the argument positions of the linked axioms.
\end{itemize}
\end{remark}

\paragraph{Non-idempotent Typings}

\begin{example}[Occurrence-level unfolding is incomplete]\label{ex:fifth-clash}
Let $\Phi = \{g : \bullet\to\bullet\to\bullet,\ f : \bullet\to\bullet,\ a,b,c : \bullet\}$, and let
\[
X : \big(((\bullet\to\bullet)\to\bullet) \to ((\bullet\to\bullet)\to\bullet) \to \bullet\big) \to (\bullet\to\bullet) \to \bullet .
\]
Consider
\[
X\,u_1\,w = g\,(f\,a)\,(f\,b), \qquad X\,u_2\,w = g\,(f\,c)\,(f\,c),
\]
where $u_1, u_2, w$ are as in Example~\ref{ex:fifth-skeleton}.
A solution is
\[
t = \lambda x_1x_2.\; \underbrace{x_1\,(\lambda z_1.\, g\,(z_1\,a)\,(z_1\,b))\,(\lambda z_2.\, x_2\,(z_2\,c))}_{n} .
\]
The node $n$ is unproductive.
The occurrence $o = z_2\,c$ lies below the call $x_2(\cdot)$, so it is far.
In equation~1 it has two uses, reached through $\nu = z_1\,a$ and $\nu' = z_1\,b$:
\begin{itemize}
\item use A: $z_2 : \omega \to 11$, an outer return of $a$;
\item use B: $z_2 : \omega \to 12$, an outer return of $b$.
\end{itemize}

\emph{No local replacement exists.}
At $o$, only $x_1, x_2, z_2$ are in scope.
Let $s$ be a replacement that does not mention $z_2$.
Its environment is identical in uses A and B, so $s$ must be typable at $11$ and at $12$ in the same environment.
Then $s\{u_1/x_1, w/x_2\} \twoheadrightarrow a$ and $\twoheadrightarrow b$, a contradiction.

\emph{Route-based resolution.}
The routes of A and B diverge at $\nu$ versus $\nu'$.
Both are opaque re-entries: the re-entered slot~$2$ contains the productive call $x_2$.
Copy re-calls replace them:
\[
\nu := x_1\,(\lambda z'_1.\,z'_1\,a)\,(\lambda z'_2.\,x_2\,(z'_2\,c)),
\qquad
\nu' := x_1\,(\lambda z'_1.\,z'_1\,b)\,(\lambda z'_2.\,x_2\,(z'_2\,c)).
\]
These evaluate to $f\,a$ and $f\,b$ in equation~1, and to $f\,c$ in equation~2.
Afterwards $z_1$ no longer occurs, so slot~$2$ of $n$ is never entered and $o$ is garbage.
Lemma~\ref{lem:fifth-route} then removes $n$.
Inside each copy, the occurrence $z'_2\,c$ has a single route.
It is unfolded by Lemma~\ref{lem:fifth-callfree}, giving for instance $x_1\,(\lambda z''_1.z''_1\,a)\,(\lambda z''_2.z''_2\,c)$.
\end{example}

\begin{definition}[Callee Closure, Transparent and Opaque Re-entries]
The \emph{callee closure} of a use consists of its linked derivation, together with the derivations reached from it through call links, recursively.
Return links, which lead to arguments, are excluded.
A re-entry is \emph{transparent} if its callee closure has $\kappa_{\mathrm{prod}} = 0$, and \emph{opaque} otherwise.
\end{definition}

A transparent re-entry is a delayed return.
Its route continues through the re-entered continuation to a return, and condition~(b) of Lemma~\ref{lem:fifth-spine} holds along the flat path.

\begin{definition}[Route-based Localisation]
Let $o$ be an occurrence of a variable bound at an unproductive node $n$.
Two uses of $o$ \emph{diverge at step $m$} if their routes enter the same slot through different occurrences $\nu_m \neq \nu'_m$.
\begin{enumerate}
\item If no two uses diverge, unfold $o$:
\begin{itemize}
\item if its final derivations are call-free, by Lemma~\ref{lem:fifth-callfree};
\item if its uses are transparent re-entries, by a skeleton re-call whose route is extended to the eventual return.
\end{itemize}
\item Otherwise, unfold the occurrences at the first divergence step instead:
\begin{itemize}
\item transparent ones by extended skeleton re-calls;
\item opaque ones by \emph{copy re-calls}, i.e.\ a skeleton up to $\nu_m$ followed by a copy of the re-entered continuation in its slot.
\end{itemize}
\end{enumerate}
\end{definition}

The soundness of each step is by Lemma~\ref{lem:fifth-repl}.
The required derivation is assembled from the characteristic one:
\begin{itemize}
\item route types are pruned and retargeted;
\item the derivations of the copied continuations are taken from their linked elements.
\end{itemize}

\begin{lemma}[Separator Bound, OPEN]\label{lem:fifth-separator}
Route-based localisation terminates on a minimal solution.
Moreover, the following situations occur at most $W_{\mathrm{sep}}$ times along any branch, for a computable $W_{\mathrm{sep}}$:
\begin{itemize}
\item a copy re-call would have to place its copy in a slot that is already used earlier on its route (same-slot recursion);
\item uses diverge inside a skipped black segment through a call of another main variable.
\end{itemize}
\end{lemma}

Lemma~\ref{lem:fifth-separator} replaces Lemma~\ref{lem:fifth-residual}.
Together with Proposition~\ref{prop:fifth-width-red}, it yields Lemma~\ref{lem:fifth-width}.
It corresponds to Stirling's bound on separators.
A plausible strategy is to charge each separator either to a production (at most $P$ in total) or to a divergence decided by some $u_i^j$.
The latter is bounded by the nesting depth of polynomials along a route within one call.

\begin{remark}[Detection is type-theoretic]
By de~Carvalho's correspondence, a multi-type derivation of $(\lambda\bar x.t)\,\bar u_i$ records a run of the Krivine machine.
Each judgement of an occurrence is a visit, and links are the environment pointers (Stirling's look-up tables).
Hence the route of every use, and every divergence, can be read off the derivation.
In system~\textbf{R}, uses with different typings occupy different coordinates.
Uses with identical typings are interchangeable for every replacement.
\end{remark}

\begin{definition}[Route, Divergence]
Let $J$ be a judgement of an occurrence $o$ of a variable bound at $n$.
The \emph{route} of $J$ is the chain of call links from the head call of the linked use of the main variable of $n$ down to $J$.
It records the black occurrences $\nu_1, \ldots, \nu_{s-1}$ through which slots are entered.
Two judgements of $o$ \emph{diverge} if their routes enter the same slot at the same step through different occurrences.
\end{definition}

\begin{lemma}[No Local Replacement]\label{lem:fifth-nolocal}
Suppose that the only introduced variables in scope at $o$ are bound by the binder of its head.
Then every replacement $s$ for $o$ that avoids this binder satisfies $\FV(s) \subseteq \bar x$.
Consequently, if two judgements of $o$ in equation $i$ have targets $p \neq q$ with $r_i|_p \neq r_i|_q$, no such replacement exists.
\end{lemma}

\begin{proof}
In both judgements, $s\{\bar u_i/\bar x\}$ would be closed and typable at $p$ and at $q$.
By Lemma~\ref{lem:fifth-char}, it would then reduce both to $r_i|_p$ and to $r_i|_q$.
\end{proof}

Example~\ref{ex:fifth-clash} is an instance of Lemma~\ref{lem:fifth-nolocal}.

\begin{lemma}[Uses are Redistributed]\label{lem:fifth-redistribute}
Let a skeleton re-call or a copy re-call replace an occurrence.
Then a characteristic multi-type derivation of the new solution arises from the old one by moving sub-derivations:
\begin{itemize}
\item the elements of a copied continuation, or of a copied exit term, that are linked through the replaced use move into the copy;
\item the remaining elements stay in place;
\item the re-call adds only the judgements of its direct references and of its route, and its dummies remain untyped.
\end{itemize}
In particular, $\kappa_{\mathrm{prod}}$ is unchanged, and no judgement of a non-direct occurrence is duplicated.
\end{lemma}

\begin{proof}[Proof sketch]
Non-idempotent derivations use each argument element exactly once.
The replaced use owned its linked white element.
That element, pruned to the route and retargeted, becomes the derivation of the new call.
The continuation and exit-term elements linked to it are re-attached to the copies.
\end{proof}

Let $\mu$ be the number of judgements of non-direct occurrences of variables bound at unproductive nodes.
Let $\delta$ be the number of unordered pairs of diverging judgements of the same occurrence.

\begin{corollary}[Termination]\label{cor:fifth-termination}
Each step of route-based localisation decreases $(\mu, \delta)$ lexicographically.
\begin{itemize}
\item A skeleton step on a non-diverging occurrence removes its judgements, so $\mu$ decreases.
\item A copy step at a first divergence separates the diverging pair, so $\delta$ decreases.
It does not increase $\mu$, by Lemma~\ref{lem:fifth-redistribute}.
\end{itemize}
Hence route-based localisation terminates.
\end{corollary}

\begin{lemma}[Blocked References, OPEN]\label{lem:fifth-blocked}
After exhaustive route-based localisation, every remaining non-direct reference to a variable of an unproductive node is blocked in one of two ways:
\begin{enumerate}
\item[(B1)] \emph{scope}: an exit term on its route contains a variable of a productive node bound strictly between $n$ and the route occurrence;
\item[(B2)] \emph{same-slot recursion with output}: its route revisits a slot whose earlier visit produces output, so the slot would need a skeleton and a copy at once.
\end{enumerate}
The open claim is that the number of variables with blocked references below any $\mu$ is bounded by a computable function of $P$, the number of productive nodes, and the nesting depth of polynomials in the arguments.
\end{lemma}

By Proposition~\ref{prop:fifth-width-red} and Corollary~\ref{cor:fifth-termination}, Lemma~\ref{lem:fifth-blocked} implies Lemma~\ref{lem:fifth-width}.
In case (B2), the revisits of one slot along a route within one call are bounded by the nesting depth of polynomials in $u_i^j$.
Each blocking visit contains a production, which suggests charging (B2) to productions.
In case (B1), the binders involved belong to at most $P$ productive nodes.


\begin{remark}[Drivers of Dimension]
Typings of an occurrence differ only through the assumptions of its free variables.
Variation comes from three sources:
\begin{itemize}
\item equations (a factor of at most $m$);
\item routing by $u$ (switches), where the same occurrences are reached with different polynomials;
\item divergence, where different occurrences lie on the routes.
\end{itemize}
Skeleton re-calls serve the second source uniformly, and copy re-calls separate the third.
Unbounded growth requires unboundedly many free introduced variables, i.e.\ unbounded width.
Hence Corollaries~\ref{cor:fifth-termination} and~\ref{cor:fifth-width-dim} together with Proposition~\ref{prop:fifth-width-red} give
\[
\dim \le D\bigl(1 + hkP + W_{\mathrm{blocked}}\bigr),
\]
where $W_{\mathrm{blocked}}$ is the bound claimed in Lemma~\ref{lem:fifth-blocked}.
Lemma~\ref{lem:fifth-blocked} is the only missing ingredient.
Corollary~\ref{cor:fifth-width-dim} also supersedes Lemma~\ref{lem:fifth-dim-bound}: it bounds the dimension by width rather than by the number of occurrences of main variables.
\end{remark}

\subsection{Machines on the Characteristic Derivation}
\label{sec:fifth-machines}

We use sequence types, i.e.\ non-idempotent and non-commutative intersections~\cite{CatoziDLV26}, with the positional atoms of Lemma~\ref{lem:eq_character}.
Elements of a sequence are matched to specific occurrences, so links are canonical.
The \emph{depth} of an atom occurrence in a type is the number of sequences enclosing it.

\begin{lemma}[Depth at Order Five]\label{lem:fifth-depth}
In a characteristic derivation of $(\lambda\bar x.t)\,\bar u_i$ for an instance of order at most~$5$, every atom occurrence on the right of $\vdash$ has depth at most~$4$.
\end{lemma}

\begin{proof}
A type refining a simple type of order $o$ has atom depth at most $o - 1$.
The largest type occurring is that of $\lambda\bar x.t$, of order at most $5$.
\end{proof}

\begin{proposition}[IAM at Order Five, transfer to be checked]\label{prop:fifth-iam}
Jumps of the PaJAM with parameter $k$ skip only atom occurrences of depth greater than $2k+1$ (Proposition~10 of~\cite{CatoziDLV26}).
Hence, by Lemma~\ref{lem:fifth-depth}, PaJAM$(2)$ never jumps on characteristic derivations of order-$5$ instances and coincides with the IAM.
The IAM visits every atom occurrence exactly once (Proposition~9 of~\cite{CatoziDLV26}).
\end{proposition}

\begin{definition}[Resolution Trajectory]
Consider a visit of the IAM to an occurrence $o$ whose head is a variable $z$.
Its \emph{resolution trajectory} is the segment of the run from the head of $o$ to the head of the term substituted for $z$.
Concatenating resolution trajectories until the run reaches a black exit term or a production yields the \emph{trajectory} of the visit.
\end{definition}

\begin{proposition}[Skeleton = Trajectory, claim]\label{prop:fifth-trajectory}
Consider a use whose route has no output on the white side.
The skeleton re-call $R_S$ of Lemma~\ref{lem:fifth-spine} consists of the constructors visited by the trajectory of the use, with the contexts skipped by the variable-to-binder transitions removed.
The IAM run of $R_S$ visits the same white constructors and reaches the same exit term with the same atom labels; this is Stirling's Fact~36.
Two judgements of $o$ diverge iff their trajectories enter a slot through different occurrences.
A copy re-call additionally materialises the closure that the KAM builds when entering the re-entered continuation.
\end{proposition}

\begin{proposition}[Stirling Positions, claim]\label{prop:fifth-positions}
JAM states ($k = 0$) on the characteristic derivation correspond to positions of Stirling's game:
\begin{itemize}
\item the subterm of the state is the node;
\item the label $p$ of the marked atom determines the goal $r_i|_p$;
\item the log is the look-up table.
\end{itemize}
A stage contributes iff the label of the marked atom changes.
\end{proposition}

\begin{remark}[Tight Typings]
By~\cite{AccattoliGK18}, tight derivations have split indices: $\beta$-steps and normal-form size.
These indices are exact, and they are determined by the final judgement alone.
With $(\Gamma_i^\natural, \varepsilon)$ as final judgement, this yields Lemma~\ref{lem:fifth-conservation}.
It also makes $\kappa$, $\mu$ and $\delta$ (Corollary~\ref{cor:fifth-termination}) invariants of the solution, independent of the chosen derivation.
The transfer requires leftmost evaluation with neutral terms, since our normal forms are headed by constants.
\end{remark}

\begin{remark}[What Remains]
If Proposition~\ref{prop:fifth-positions} holds, Lemma~\ref{lem:fifth-blocked} is Stirling's bound on separators (at most $pq^{p-1}|u|$ with $p = 2$), restated on the characteristic derivation.
Proving it then amounts to translating the proof of Theorem~37 of~\cite{stirling2009}: stages, families and separators become segments of IAM runs, link descendants and shared occurrences.
\end{remark}

\subsection{The SIAM as Reference Model}
\label{sec:fifth-siam}

Let $\pi$ be a characteristic derivation of $(\lambda\bar x.t)\,\bar u_i$ with sequence types and positional atoms.
The SIAM~\cite{AccattoliDLV21} acts on $\pi$.
Its states are occurrences of atoms on the right of $\vdash$, together with a direction.
Its transitions connect an atom occurrence in a judgement with the corresponding occurrence in an adjacent judgement:
\begin{itemize}
\item a parent or child in the derivation;
\item a variable axiom and the matching element in the type of its binder;
\item a sequence element of an argument and the matching domain element of the function.
\end{itemize}
We extend it by one rule for constants.
When an axiom $c : [p1] \to \cdots \to [pk] \to p$ is reached at its target $p$, the run branches into the occurrences $p1, \ldots, pk$.
This mirrors Stirling's $\forall$-moves.

\begin{definition}[Interaction Tree]
The \emph{interaction tree} of $\pi$ is the tree of SIAM runs from the root occurrence $\varepsilon$, branching at constants.
\end{definition}

\begin{proposition}[Properties, transfer to be checked]\label{prop:fifth-siam}
\leavevmode
\begin{enumerate}
\item The SIAM is bi-deterministic, and every atom occurrence of $\pi$ lies on exactly one node of the interaction tree (Proposition~13.1 and Theorem~14.5 of~\cite{AccattoliDLV21}).
\item At order~$5$, every atom occurrence has depth at most~$4$ (Lemma~\ref{lem:fifth-depth}).
\item The branches of the interaction tree, restricted to occurrences of depth at most~$1$, are the plays of Stirling's game.
A stage contributes iff the atom label changes along its segment.
\item Consider a maximal segment of depth at least~$2$ between two visits of depth at most~$1$.
It is a resolution trajectory.
The term occurrences of its judgements form the skeleton of Lemma~\ref{lem:fifth-callfree}.
\item Two judgements of one occurrence diverge iff their trajectory segments enter the same slot through judgements of different occurrences.
\item Uses are sequence elements.
Re-calls move elements between calls and reconnect the path (Lemma~\ref{lem:fifth-redistribute}).
\end{enumerate}
\end{proposition}

\begin{remark}[Choice of Machine]
The SIAM needs no logs, tapes, closures or jumps, because all copies are present in $\pi$.
\begin{itemize}
\item The KAM represents copies by closures; in $\pi$ these are sequence elements.
\item The JAM and PAM skip exactly the segments of depth at least~$2$, i.e.\ the trajectories that unfolding must materialise.
\item The cost of the IAM grows with the size of types, but at order~$5$ the depth of types is bounded.
\end{itemize}
Accordingly, we state routes, divergence, contribution and unfolding as properties of the interaction tree.
Lemma~\ref{lem:fifth-blocked} then becomes a statement about segments of depth at least~$2$ that are shared by several branches; these are Stirling's separators.
\end{remark}

\begin{remark}[Required Extensions]
The results of~\cite{AccattoliDLV21} concern closed call-by-name evaluation with a single ground type and abstractions as normal forms.
We need open terms with first-order constants, strong evaluation into the arguments of constants, and positional atoms.
The head-evaluation $\lambda$IAM for open terms~\cite{AccattoliDLV20} is the natural starting point.
\end{remark}

\section{Routes as Label Bindings}
\label{sec:fifth-labels}

This section replaces Section~\ref{sec:fifth-machines} and the remark ``Detection is type-theoretic''.
Following Kobayashi~\cite{Kobayashi13}, we label arguments and head occurrences of variables.
\emph{Link bindings} then record which argument is substituted for which occurrence, and at which type.
Linked polynomials, routes and exits become link bindings in one derivation of $(\lambda\bar x.t)\,\bar u_i$.
Their properties follow from labelled versions of Kobayashi's Lemmas~3.8--3.11~\cite{Kobayashi13}; no machine model is needed.

\subsection{Labelled Characteristic Typing}

\paragraph{Labels.}
In $S_i = (\lambda\bar x.t)\,u_i^1\ldots u_i^n$ we attach pairwise distinct labels of two kinds.
\begin{itemize}
\item \emph{Argument labels} $\gamma$:
  \begin{itemize}
  \item $\varsigma$ on each continuation argument of a main node (black);
  \item $\epsilon$ on each argument of a use of an introduced variable (black);
  \item $\ell$ on each polynomial of $u_i^j$, i.e.\ on each argument of a call $F\,\bar\pi$ (white).
  \end{itemize}
\item \emph{Occurrence labels} $\theta$:
  \begin{itemize}
  \item $m$ on each occurrence of a main variable (black);
  \item $\mu$ on each head occurrence of an introduced variable (black);
  \item $\kappa$ on each occurrence of some $F$ (white);
  \item $\rho$ on each parameter occurrence in a polynomial (white).
  \end{itemize}
\end{itemize}
We write $S_i^\sharp$ for the labelled term.
Reduction copies labelled subterms, so a label may occur several times in a reduct.

\paragraph{Types and rules.}
Types are as in Section~\ref{sec:fifth-typed}, except that a type may carry one argument label as a \emph{tag}, written $A^\gamma$.
The universe of types remains finite.
Environments are sets of bindings $x : A$ for variables and constants, and $\gamma : A$, $\theta : A^\gamma$ for labels.
We write $\Gamma_V$ and $\Gamma_L$ for the two parts.

The rules are Kobayashi's relevant rules, without weakening:
\[
\frac{}{\{x : A\} \vdash x : A}
\qquad
\frac{\Gamma \cup \{x : A_k \mid k \in K\} \vdash s : B \quad x \notin \mathrm{dom}(\Gamma)}{\Gamma \vdash \lambda x.s : \{A_k \mid k \in K\} \to B}
\]
\[
\frac{\Gamma_0 \vdash s : \{A_k \mid k \in K\} \to B \qquad \Gamma_k \vdash u : A_k \ \ (k \in K)}{\Gamma_0 \cup \bigcup_{k \in K} \Gamma_k \vdash s\,u : B}
\]
In the application rule, $A_k = A_{k'}$ is allowed for $k \neq k'$, with different environments.
Argument types must equal domain elements, tags included.
A tag on the type of a function in head position is ignored.
Constants are variables, and the characteristic environment $\Gamma_i$ of Lemma~\ref{lem:eq_character} is part of $\Gamma_V$.

Labels are typed by
\[
\frac{\Gamma \vdash s : A}{\Gamma \cup \{\gamma : A\} \vdash s^\gamma : A^\gamma}\ (\mathrm{Arg})
\qquad\qquad
\frac{\Gamma \vdash s : A^\gamma}{\Gamma \cup \{\theta : A^\gamma\} \vdash s^\theta : A}\ (\mathrm{Occ})
\]
In (Occ) the tag may be absent; this is the case for main variables, whose arguments $u_i^j$ carry no label.

\paragraph{Labelled reduction.}
A \emph{positioned subterm} of a reduct is a subterm $s$ of $C[s]$ where the context $C$ consists of constants only.
Its position is that of the hole.
Labelled reduction consists of leftmost-outermost $\beta$-steps and of (R-Lab) steps, which remove a label at the head of a positioned subterm.
It terminates in $r_i$, which contains no labels.

\begin{lemma}[Kobayashi's Lemmas~3.8--3.11, labelled and positional]\label{lem:fifth-kob}
\leavevmode
\begin{enumerate}
\item \emph{Substitution.}
Suppose $\Gamma_0 \cup \{x : A_1, \ldots, x : A_n\} \vdash s : B$ with pairwise distinct $A_k$ and $x \notin \mathrm{dom}(\Gamma_0)$, and $\Gamma_k \vdash u : A_k$ for all $k$.
Then $\Gamma_0 \cup \Gamma_1 \cup \cdots \cup \Gamma_n \vdash s[u/x] : B$.
\item \emph{Subject reduction.}
Let $\Gamma \vdash S' : \varepsilon$ and $\theta : A^\gamma \in \Gamma_L$.
Then one of the following holds:
  \begin{itemize}
  \item $S'$ has a positioned subterm $(s^\gamma)^\theta\,s_1\ldots s_k$ at position $\tgt(A)$, typed according to $A$;
  \item $S' \to S''$ with $\Gamma'' \vdash S'' : \varepsilon$ and $\theta : A^\gamma \in \Gamma''_L$.
  \end{itemize}
\item \emph{Inverse substitution.}
If $\Gamma \vdash s[u/x] : B$, then there are a finite set $K$, types $A_k$ and environments $\Gamma_k$ for $k \in \{0\} \cup K$ such that
\[
\Gamma_0 \cup \{x : A_k \mid k \in K\} \vdash s : B,
\qquad
\Gamma_k \vdash u : A_k \ \ (k \in K),
\qquad
\Gamma = \bigcup_{k \in \{0\} \cup K} \Gamma_k .
\]
\item \emph{Subject expansion.}
If $\Gamma'' \vdash S'' : \varepsilon$ and $S' \to S''$, then $\Gamma \vdash S' : \varepsilon$ for some $\Gamma$ with $\Gamma_V = \Gamma''_V$ and $\Gamma_L \supseteq \Gamma''_L$.
\end{enumerate}
\end{lemma}

\begin{proof}
As in~\cite{Kobayashi13}, where the proofs of~(1) and~(3) are given in the extended version.
Tags are part of types and do not change the arguments.
Constants are variables bound in $\Gamma_i$.
Positioned subterms replace Kobayashi's branch selection (R-Const), because all branches are typed.
Item~(3) is exact because the application rule admits repeated argument types (Section~\ref{sec:fifth-tight}).
For a $\beta$-step, item~(4) follows from item~(3).
For an (R-Lab) step, rule (Arg) or (Occ) adds the binding of the removed label.
\end{proof}

\begin{theorem}[Links as Bindings]\label{thm:fifth-links}
Let $\lambda\bar x.t$ be a solution.
Expanding the characteristic derivation of $\Gamma_i \vdash r_i : \varepsilon$ along the labelled reduction of $S_i^\sharp$ yields a derivation $\mathcal{D}_i$ of $\Gamma_i \cup \Gamma_L \vdash S_i^\sharp : \varepsilon$, the \emph{canonical labelled derivation}.
For every occurrence label $\theta$, argument label $\gamma$ and type $A$, the binding $\theta : A^\gamma$ belongs to $\Gamma_L$ iff some reduct has a positioned subterm $(s^\gamma)^\theta\,s_1\ldots s_k$ at position $\tgt(A)$, typed according to $A$.
The same holds for untagged bindings $\theta : A$ and for argument bindings $\gamma : A$.
\end{theorem}

\begin{proof}
The derivation exists by Lemma~\ref{lem:fifth-kob}(4), which preserves $\Gamma_V = \Gamma_i$ exactly.

($\Leftarrow$)
In the reduct with the positioned subterm, the (R-Lab) step for $\theta$ is inverted by (Occ), which adds $\theta : A^\gamma$.
Lemma~\ref{lem:fifth-kob}(4) keeps this binding up to $S_i^\sharp$.

($\Rightarrow$)
By Lemma~\ref{lem:fifth-kob}(2) and termination, as in the proof of~\cite[Theorem~3.6]{Kobayashi13}.
The derivation of $r_i$ has no label bindings, so $\theta : A^\gamma$ must be consumed at a positioned head.
\end{proof}

\subsection{Links, Routes and Exits}

\begin{definition}[Links]
In $\mathcal{D}_i$, the bindings of occurrence labels are \emph{links}:
\begin{itemize}
\item a \emph{main link} $m : B$: the occurrence $m$ of $x_j$ uses $u_i^j$ at $B$;
\item a \emph{call link} $\kappa : C^\varsigma$: the call site $\kappa$ in $u_i^j$ enters the slot $\varsigma$ at $C$;
\item a \emph{use link} $\mu : A^\ell$: the use $\mu$ applies the polynomial $\ell$ at $A$, and $\ell$ is its \emph{linked polynomial};
\item a \emph{return link} $\rho : a^\epsilon$: the parameter occurrence $\rho$ yields the black argument $\epsilon$ at the atom $a$.
\end{itemize}
\end{definition}

The white side of every link is a label in the judgement.
In particular, the types in $T_i^j$ are tagged.
Through its tags, a type $B$ of $u_i^j$ lists which call sites enter which slots, and which polynomials are passed at which types.
No derivation of $u_i^j$ has to be fixed for the types used, and the corresponding caveat in the remark on Example~\ref{ex:fifth-skeleton} is obsolete.

\paragraph{Kinds are syntactic.}
Given a use link $\mu : A^\ell$, the kind of the use is determined by the head of the body of $\pi_\ell$:
\begin{itemize}
\item a constant gives an output;
\item some $F$ gives a re-entry;
\item a parameter of $\pi_\ell$ gives an own return;
\item a parameter of an enclosing polynomial gives an outer return.
\end{itemize}
The final derivation is \emph{call-free} if the environment of the judgement of $\pi_\ell$ at $A^\ell$ in $\mathcal{D}_i$ contains no call link.

\begin{definition}[Route, Exit]
Let $\mu : A^\ell$ be a use link of an occurrence bound at a main node with main link $m : B$.
A \emph{route} for it is a sequence of links
\[
m : B,\ \ \kappa_1 : C_1^{\varsigma_1},\ \ \mu_1 : A_1^{\ell_1},\ \ \ldots,\ \ \mu_{s-1} : A_{s-1}^{\ell_{s-1}},\ \ \kappa_s : C_s^{\varsigma_s},\ \ \mu : A^\ell .
\]
Write $\ell_s = \ell$ and $A_s = A$.
The route must satisfy three conditions:
\begin{enumerate}
\item \emph{Syntax.}
$\kappa_1$ lies in the body of $u_i^j$, and $\kappa_{r+1}$ lies in the body of $\pi_{\ell_r}$.
$\ell_r$ is the $g_r$-th argument of $\kappa_r$, and the head of $\mu_r$ is bound by the slot $\varsigma_r$.
\item \emph{Types.}
$A_r^{\ell_r}$ belongs to the $g_r$-th domain of $C_r$.
\item \emph{Routing.}
$\tgt(C_1) = \tgt(B)$ and $\tgt(C_{r+1}) = \tgt(A_r)$.
\end{enumerate}
By Lemma~\ref{lem:fifth-head}, condition~(3) says that each call on the route is the head of its white region.

An \emph{exit} is a return link $\rho : a^\epsilon$ with $a = \tgt(A)$, where $\rho$ is the head of the body of $\pi_\ell$.
Suppose $\rho$ is the $k$-th parameter of $\pi_{\ell_r}$ with $r \le s$.
Then $a^\epsilon$ belongs to the $k$-th domain of $A_r$, and $\epsilon$ labels the \emph{exit term}, the $k$-th argument of $\mu_r$.
\end{definition}

\begin{lemma}[Routes Exist]\label{lem:fifth-routes}
Every use link of an occurrence bound at an unproductive main node has a route.
If the use is a return, the route has an exit.
\end{lemma}

\begin{proof}
By Theorem~\ref{thm:fifth-links}, the use link is realised in the labelled reduction.
Trace back the creation of the polynomial $\ell$:
\begin{itemize}
\item $\ell$ was substituted at the call site $\kappa_s$ of which it is an argument;
\item $\kappa_s$ reached a positioned head either inside the body of $u_i^j$, or inside the evaluation of the polynomial containing it, which was applied by a use $\mu_{s-1}$.
\end{itemize}
Each of these head occurrences is a link of $\mathcal{D}_i$ by Theorem~\ref{thm:fifth-links}.
The calls are heads of their regions by Lemma~\ref{lem:fifth-routing}, which gives the routing condition.
A return parameter reaches a positioned head at $\tgt(A)$, which gives the exit.
\end{proof}

\begin{remark}[Divergence from Bindings]
Two use links $\mu : A^\ell$ and $\mu : A'^{\ell'}$ of the same occurrence \emph{diverge} if they have routes entering the same slot at the same step through different use labels $\mu_r \neq \mu'_r$.
This is a property of $\Gamma_L$.
Links with equal types are merged by idempotency, and such links are interchangeable for every replacement.
\end{remark}

Lemmas~\ref{lem:fifth-spine} and~\ref{lem:fifth-callfree} are restated with these notions:
\begin{itemize}
\item the linked use $\nu_r$ is the occurrence labelled $\mu_r$;
\item the final derivation $\mathcal{E}$ is the judgement of $\pi_\ell$ at $A^\ell$ in $\mathcal{D}_i$;
\item the exit terms are given by return links.
\end{itemize}
The proofs are unchanged.
The pruned and retargeted derivation of $u_i^j$ at $B^*$ is assembled from white judgements of $\mathcal{D}_i$.

\subsection{Tightness Check}
\label{sec:fifth-tight}

A labelled derivation is \emph{tight} if every binding in every environment is used by an axiom, by (Arg) or by (Occ).
Since the rules admit no weakening, every derivation is tight.
The real question is whether the lemmas above preserve environments \emph{exactly}.

\begin{remark}[Repeated Argument Types]
By~\cite[Remark~8.1]{Kobayashi13}, inverse substitution is exact, i.e.\ $\Gamma = \bigcup_k \Gamma_k$, only if the application rule admits repeated equal argument types with different environments.
Otherwise only $\Gamma' \subseteq \Gamma$ holds.
The reason is that occurrences of $u$ typed at the same type in different environments would have to share one derivation, and the bindings of the others are lost.
Kobayashi's example is $\{x : r, y : r\} \vdash (\lambda z.z)(a\,x\,y) : r$.
It needs two premises $a\,x\,y : r$, one with environment $\{x : r\}$ and one with $\{y : r\}$.
\end{remark}

For the type systems used in this paper:
\begin{itemize}
\item The labelled system above admits repetitions, so Lemma~\ref{lem:fifth-kob}(3) is exact.
By Lemma~\ref{lem:fifth-kob}(4), the canonical labelled derivation of every solution has $\Gamma_V = \Gamma_i$, and $\Gamma_L$ consists exactly of the realised links.
\item In system~\textbf{R}, repeated equal types occupy distinct coordinates with distinct environment columns, so inverse substitution is exact as well.
\item The set-based system of Section~\ref{sec:fifth-typed} has one premise per type and top-down environments.
It suffices for the soundness of replacements (Lemma~\ref{lem:fifth-repl}), but link bindings can be lost under expansion.
Statements about links, routes, exits and tightness are therefore made in the labelled system.
\end{itemize}

This replaces the claim that tightness is preserved by the replacements:
\begin{itemize}
\item Replacements are justified by Lemma~\ref{lem:fifth-repl}.
\item The new solution has its own canonical labelled derivation by Theorem~\ref{thm:fifth-links}, which is tight with $\Gamma_V = \Gamma_i$.
\item Grafting derivations directly preserves tightness only after pruning: each assumption whose last use was replaced must be removed from its binder.
\item Pruning changes head types $B$ into pruned types $B'$.
These remain in $T_i^j$, because restricting a derivation of $u_i^j$ to the remaining argument premises is again a derivation, by exactness of Lemma~\ref{lem:fifth-kob}(3).
\end{itemize}
Counting statements (Section~\ref{sec:fifth-colours}) still require multi types; the labels carry over to them unchanged.

\begin{remark}[Outlook: Pumping]
In Kobayashi's proof of the pumping lemma, a repeated binding of the same label at the same type along a chain makes the segment in between removable.
Here, the links with target $a$ form the chain of head terms at position $a$.
This chain produces no output except its final constant.
A repetition of the same occurrence label at the same type in this chain is the typed analogue of Stirling's T2.
It is the natural candidate for proving Lemma~\ref{lem:fifth-blocked} on flat segments.
\end{remark}

\section{Examples}
\label{sec:examples}

Type atoms are positions read from the node to the root, e.g.\ $a : 11$ and $b : 12$ in $g\,(f\,a)\,(f\,b)$.
$\omega$ is the empty set, and singleton braces are omitted.
A single equation is always solved by $\lambda\bar x.\,r_1$, so main nodes are forced only by variation between instances.
Each example isolates one feature, stated at its end.

\subsection{Basic Properties}

\begin{example}[Garbage, Projection, Routing]\label{ex:ex-collapse}
Let $\Phi = \{a,b : \bullet\}$, $X : (((\bullet\to\bullet\to\bullet)\to\bullet)\to\bullet)\to\bullet$ and $u = \lambda F.\,F\,(\lambda y_1y_2.\,y_1)$.
Take $X\,u = a$ and $t = \lambda x.\,x\,(\lambda z.\,z\,a\,b)$.
With $\Gamma = \{a : \varepsilon\}$ the head type is $((\varepsilon \to \omega \to \varepsilon) \to \varepsilon) \to \varepsilon$.
\begin{itemize}
\item $\Inst(b) = \emptyset$, so $b$ is garbage (Corollary~\ref{cor:fifth-garbage}).
\item The only instance of $z\,a\,b$ has $z : \varepsilon \to \omega \to \varepsilon$, so Lemma~\ref{lem:fifth-proj} gives $x\,(\lambda z.\,a)$.
\item Then $z$ no longer occurs, and the slot has target $\varepsilon$, so Lemma~\ref{lem:fifth-route} gives $a$.
\end{itemize}

\emph{Feature.}
The basic simplifications are decided by instances alone.
Projection needs only one projection index across all instances.
\end{example}

\begin{example}[Switch]\label{ex:ex-switch}
Let $\Phi = \{a,b : \bullet\}$ and $X : (((\bullet\to\bullet\to\bullet)\to\bullet)\to\bullet)\to\bullet$.
Let $u_1 = \lambda F.\,F\,(\lambda y_1y_2.\,y_1)$ and $u_2 = \lambda F.\,F\,(\lambda y_1y_2.\,y_2)$.
Take $X\,u_1 = a$, $X\,u_2 = b$ and $t = \lambda x.\,x\,(\lambda z.\,z\,a\,b)$.
The instances of $z\,a\,b$ are $z : \varepsilon \to \omega \to \varepsilon$ (equation~1) and $z : \omega \to \varepsilon \to \varepsilon$ (equation~2).
Hence $x$ has the head types $((\varepsilon \to \omega \to \varepsilon) \to \varepsilon) \to \varepsilon$ and $((\omega \to \varepsilon \to \varepsilon) \to \varepsilon) \to \varepsilon$, one coordinate each.
Projection fails, and $b$ is not garbage.
Every solution contains $x$: an $x$-free solution is closed and would reduce both to $a$ and to $b$.

\emph{Feature.}
Variation between equations is carried by the arguments $u_i^j$.
It can be recovered only by calling a main variable.
This is the information that re-calls transport.
\end{example}

\begin{example}[Intersections below Introduced Variables]\label{ex:ex-pos}
Let $\Phi = \{g : \bullet\to\bullet\to\bullet,\ a : \bullet\}$, $X : (((\bullet\to\bullet)\to\bullet)\to\bullet)\to\bullet$ and $u = \lambda F.\,F\,(\lambda y.\,g\,y\,y)$.
Take $X\,u = g\,a\,a$ and $t = \lambda x.\,x\,(\lambda z.\,z\,a)$.
Then $\Gamma = \{g : 1 \to 2 \to \varepsilon,\ a : \{1,2\}\}$, and the polynomial has type $\{1,2\} \to \varepsilon$.
Hence $z : \{1,2\} \to \varepsilon$, and the black $a$ is typed twice.

\emph{Feature.}
Intersections also arise at arguments of introduced variables, not only at main nodes (cf.\ the remark on Lemma~\ref{lem:fifth-dim-bound}).
They range over positions of one right-hand side, which should cost only a factor $|\Pos(r_i)|$ per coordinate.
One exit term may serve several returns at distinct targets.
\end{example}

\begin{example}[Instances Multiply]\label{ex:ex-instances}
Let $\Phi = \{g : \bullet\to\bullet\to\bullet,\ a,b : \bullet\}$, $X : ((\bullet\to\bullet)\to\bullet)\to\bullet$ (order $4$) and $w = \lambda H.\,g\,(H\,a)\,(H\,b)$.
Take $X\,w = g\,(g\,(g\,a\,a)\,(g\,a\,b))\,(g\,(g\,b\,a)\,(g\,b\,b))$ and
\[
t = \lambda x.\,x\,(\lambda h_1.\,\underbrace{x\,(\lambda h_2.\,g\,h_1\,h_2)}_{n'}).
\]
The outer node has a single instance.
Since $w$ calls $H$ twice, $n'$ has two instances:
\begin{itemize}
\item target $1$ with $h_1 : \{111, 121\}$;
\item target $2$ with $h_1 : \{112, 122\}$.
\end{itemize}
Its body $g\,h_1\,h_2$ has four instances, at targets $11$, $21$, $12$ and $22$.

\emph{Feature.}
Within one equation, instances multiply along nested nodes whose white side copies its continuation.
The instances are separated only by the types of black ground variables ($h_1$, $h_2$).
Hence dimension is driven by the nesting of main nodes (Lemma~\ref{lem:fifth-dim-bound}), not only by the number of equations.
\end{example}

\subsection{Unfolding}

\begin{example}[Canonical Unfolding (Flat)]\label{ex:ex-canon}
Let $\Phi = \{a,b,c : \bullet\}$ and
\[
X : (((\bullet\to\bullet\to\bullet)\to\bullet)\to\bullet) \to (((\bullet\to\bullet\to\bullet)\to\bullet)\to\bullet) \to \bullet .
\]
Let $p_1 = \lambda F.\,F\,(\lambda y_1y_2.\,y_1)$ and $p_2 = \lambda F.\,F\,(\lambda y_1y_2.\,y_2)$.
Take
\[
X\,p_1\,p_1 = a,
\qquad
X\,p_2\,p_1 = b,
\qquad
X\,p_1\,p_2 = c,
\]
and
\[
t = \lambda x_1x_2.\,\underbrace{x_1\,(\lambda z.\,\underbrace{x_2\,(\lambda z'.\,z'\,(z\,a\,b)\,c)}_{n'})}_{n}.
\]
The occurrence $\nu = z\,a\,b$ lies below $n'$.
Its instances are $z : \varepsilon \to \omega \to \varepsilon$ (equation~1) and $z : \omega \to \varepsilon \to \varepsilon$ (equation~2), both at target $\varepsilon$; equation~3 has no instance.
\begin{itemize}
\item Projection fails at $\nu$ and at $z'\,(z\,a\,b)\,c$, since the indices differ.
\item Lemma~\ref{lem:fifth-route} does not apply to $n'$, since its body uses $z'$.
\item In every instance, $(n,\nu)$ is flat and $\sigma_1$ is a singleton, so Corollary~\ref{cor:fifth-canon} applies with $B^* = B$.
\end{itemize}
This gives $\nu := x_1\,(\lambda z''.\,z''\,a\,b)$, after which Lemma~\ref{lem:fifth-route} removes $n$:
\[
\lambda x_1x_2.\,x_2\,(\lambda z'.\,z'\,(x_1\,(\lambda z''.\,z''\,a\,b))\,c).
\]

\emph{Feature.}
In the flat case the re-call reuses the head type unchanged.
Size is unchanged; what decreases is width, since the far reference to $z$ disappears.
The flat case is non-trivial only if the intermediate node uses its own binder; otherwise Lemma~\ref{lem:fifth-route} removes that node first.
\end{example}

\begin{example}[Far Switch: Target Shift]\label{ex:ex-shift}
Let $\Phi = \{f : \bullet\to\bullet,\ a,b : \bullet\}$ and $X : (((\bullet\to\bullet\to\bullet)\to\bullet)\to\bullet) \to (\bullet\to\bullet) \to \bullet$.
Let $u_1 = \lambda F.\,F\,(\lambda y_1y_2.\,y_1)$, $u_2 = \lambda F.\,F\,(\lambda y_1y_2.\,y_2)$ and $w = \lambda h.\,f\,h$.
Take $X\,u_1\,w = f\,a$, $X\,u_2\,w = f\,b$ and
\[
t = \lambda x_1x_2.\,\underbrace{x_1\,(\lambda z.\,x_2\,(z\,a\,b))}_{n}.
\]
The occurrence $\nu = z\,a\,b$ lies below the productive node $x_2(\cdot)$.
It has target $1$, with $z : 1 \to \omega \to 1$ in equation~1 and $z : \omega \to 1 \to 1$ in equation~2.
The head types of $n$ have target $\varepsilon$.
\begin{itemize}
\item Projection fails, since the indices differ.
\item Canonical unfolding fails: $(n,\nu)$ is not flat, because $x_2$ produces $f$ between the slot and $\nu$.
\item The body of $u_i$ is headed by the slot's $F$, so Lemma~\ref{lem:fifth-shift} applies.
It gives $B^*_1 = ((1 \to \omega \to 1) \to 1) \to 1$ and $B^*_2 = ((\omega \to 1 \to 1) \to 1) \to 1$.
\end{itemize}
Hence $\nu := x_1\,(\lambda z'.\,z'\,a\,b)$, and Lemma~\ref{lem:fifth-route} yields $\lambda x_1x_2.\,x_2\,(x_1\,(\lambda z'.\,z'\,a\,b))$.

\emph{Feature.}
Black output between a slot and an occurrence is harmless if the white route to the slot is output-free: the re-call is retargeted.
\end{example}

\begin{example}[Re-call Needs a Skeleton]\label{ex:ex-skeleton}
Let $\Phi = \{g,f : \bullet\to\bullet,\ a,b : \bullet\}$ and
\[
X : \big(((\bullet\to\bullet)\to\bullet) \to ((\bullet\to\bullet)\to\bullet) \to \bullet\big) \to (\bullet\to\bullet) \to \bullet .
\]
Let
\[
u_1 = \lambda F_1F_2.\,F_1\,(\lambda y.\,F_2\,(\lambda y'.\,y)),
\qquad
u_2 = \lambda F_1F_2.\,F_1\,(\lambda y.\,F_2\,(\lambda y'.\,y')),
\qquad
w = \lambda h.\,f\,h .
\]
Take $X\,u_1\,w = g\,(f\,a)$, $X\,u_2\,w = g\,(f\,b)$ and
\[
t = \lambda x_1x_2.\,\underbrace{x_1\,(\lambda z_1.\,g\,(z_1\,a))\,(\lambda z_2.\,x_2\,(z_2\,b))}_{n}.
\]
Slot~2 is entered only by a re-entry from the polynomial bound to $z_1$.
The far occurrence $o = z_2\,b$ has target $11$ in both equations:
\begin{itemize}
\item in equation~1, $z_2 : \omega \to 11$ is an outer return of the exit term $a$ of $\nu_1 = z_1\,a$;
\item in equation~2, $z_2 : 11 \to 11$ is an own return of $b$.
\end{itemize}
What fails:
\begin{itemize}
\item Projection fails: $o := b$ in equation~1, $o := a$ in equation~2.
\item Target shift fails, since $u_i$ is headed by $F_1$, not $F_2$.
\item Keeping slot~1, the re-call $x_1\,(\lambda z_1.\,g\,(z_1\,a))\,(\lambda z'_2.\,z'_2\,b)$ yields $g\,a$, resp.\ $g\,b$: it replays $g$ at target $11$.
\end{itemize}
The skeleton re-call $R_S = x_1\,(\lambda z'_1.\,z'_1\,a)\,(\lambda z'_2.\,z'_2\,b)$ of Lemma~\ref{lem:fifth-callfree} drops $g$, keeps $a$, and is placed at $o$.
A solution without far references is $\lambda x_1x_2.\,g\,(x_2\,(x_1\,(\lambda z.\,z\,a)\,(\lambda z'.\,z'\,b)))$.
Types do not determine kinds: $z_2 : \omega \to 11$ is an outer return, while $z_1 : \omega \to 1$ in equation~2 is a re-entry.

\emph{Feature.}
The route has length~$2$, and the re-call rewrites an earlier slot than the one containing $o$.
Variation between equations is still recoverable at $o$, since $R_S\{u_i/x_1\}$ differs in $i$.
\end{example}

\subsection{Limits of Local Replacement}

\begin{example}[White Output]\label{ex:ex-white}
Let $\Phi = \{g : \bullet\to\bullet\to\bullet,\ f : \bullet\to\bullet,\ a,b,c : \bullet\}$ and $X : ((\bullet\to\bullet)\to\bullet) \to (\bullet\to\bullet) \to \bullet$ (order $4$).
Let $u_1 = \lambda F.\,g\,(F\,a)\,(F\,b)$, $u_2 = \lambda F.\,g\,(F\,c)\,(F\,c)$ and $w = \lambda h.\,f\,h$.
Take $X\,u_1\,w = g\,(f\,a)\,(f\,b)$, $X\,u_2\,w = g\,(f\,c)\,(f\,c)$ and
\[
t = \lambda x_1x_2.\,x_1\,(\lambda z.\,x_2\,z).
\]
In equation~1 we have $x_1 : \{11 \to 1,\ 12 \to 2\} \to \varepsilon$.
So the far occurrence $z$ has two judgements, $z : 11$ and $z : 12$.
\begin{itemize}
\item There is no $z$-free replacement: at $o$ only $x_1, x_2$ are in scope besides $z$, and $r_1|_{11} = a \neq b = r_1|_{12}$ (Lemma~\ref{lem:fifth-nolocal}).
\item The re-call $x_1\,(\lambda z'.\,z')$ yields $g\,a\,b$.
Target shift is impossible, since $u_i$ is headed by $g$.
\item The reference is unavoidable.
$g$ must come from $u_i$, since an $x_1$-free context cannot separate $a$ from $c$.
Hence $x_1$ heads the solution, and $x_2$ must refer to its binder.
\end{itemize}

\emph{Feature.}
The separating information is which call of $F$ under a white constant entered the slot.
Such references are permanent, but their judgements are charged to white syntax: at most the number of calls of $F$ in $u_i^j$ per instance.
At order~$4$ introduced variables are ground: every use is a return, and every route has length~$1$.
\end{example}

\begin{example}[Re-entry with Output]\label{ex:ex-reentry}
Let $\Phi = \{g : \bullet\to\bullet\to\bullet,\ a,c : \bullet\}$ and $X : (((\bullet\to\bullet)\to\bullet)\to\bullet)\to\bullet$.
Let $u_1 = \lambda F.\,F\,(\lambda y.\,F\,(\lambda y'.\,y))$ and $u_2 = \lambda F.\,F\,(\lambda y.\,y)$.
Take $X\,u_1 = g\,(g\,a\,c)\,c$, $X\,u_2 = g\,a\,c$ and
\[
t = \lambda x.\,x\,(\lambda z.\,g\,(z\,a)\,c).
\]
In equation~1, $u_1$ enters the slot twice: by the head call at $\varepsilon$ and by a re-entry at $1$.
This gives $x : \{C_1, C_2\} \to \varepsilon$ with $C_1 = (11 \to 1) \to \varepsilon$ and $C_2 = (\omega \to 11) \to 1$.
The occurrence $\nu = z\,a$ has the following judgements:
\begin{itemize}
\item in equation~1, $z : 11 \to 1$ at target $1$ and $z : \omega \to 11$ at target $11$;
\item in equation~2, $z : 1 \to 1$ at target $1$.
\end{itemize}
Both visits of the continuation produce black output, so (L2) is strict in both judgements of equation~1.
\begin{itemize}
\item Target shift fails: $N_1 = \{C_2\}$, and (b) fails for $C_2$.
Indeed, $\nu := x\,(\lambda z'.\,z'\,a)$ gives $g\,a\,c \neq r_1$.
\item There is no $z$-free replacement: $r_1|_1 = g\,a\,c \neq a = r_1|_{11}$ (Lemma~\ref{lem:fifth-nolocal}).
\item Separating the inner visit at its route step $\nu$ would need slot~1 to hold the skeleton $\lambda z'.\,z'\,a$ and a copy of $\lambda z.\,g\,(z\,a)\,c$ at once.
\end{itemize}

\emph{Feature.}
This is same-slot recursion with output, case~(B2) of Lemma~\ref{lem:fifth-blocked}.
The separating information is the re-entry depth inside $u_1$, and neither a skeleton nor a copy re-call applies.
Here $\nu$ is direct; below a productive node it would be a blocked far reference.
Each blocked visit is a strict step, which suggests charging (B2) to Lemma~\ref{lem:fifth-branch}.
\end{example}

\begin{example}[No Local Replacement: Divergence]\label{ex:ex-clash}
Let $\Phi = \{g : \bullet\to\bullet\to\bullet,\ f : \bullet\to\bullet,\ a,b,c : \bullet\}$ and
\[
X : \big(((\bullet\to\bullet)\to\bullet) \to ((\bullet\to\bullet)\to\bullet) \to \bullet\big) \to (\bullet\to\bullet) \to \bullet .
\]
Let
\[
u_1 = \lambda F_1F_2.\,F_1\,(\lambda y.\,F_2\,(\lambda y'.\,y)),
\qquad
u_2 = \lambda F_1F_2.\,F_1\,(\lambda y.\,F_2\,(\lambda y'.\,y')),
\qquad
w = \lambda h.\,f\,h .
\]
Take $X\,u_1\,w = g\,(f\,a)\,(f\,b)$, $X\,u_2\,w = g\,(f\,c)\,(f\,c)$ and
\[
t = \lambda x_1x_2.\,\underbrace{x_1\,(\lambda z_1.\,g\,(z_1\,a)\,(z_1\,b))\,(\lambda z_2.\,x_2\,(z_2\,c))}_{n}.
\]
In equation~1, the far occurrence $o = z_2\,c$ has two judgements:
\begin{itemize}
\item $z_2 : \omega \to 11$, reached through $\nu = z_1\,a$;
\item $z_2 : \omega \to 12$, reached through $\nu' = z_1\,b$.
\end{itemize}
At $o$ only $x_1, x_2, z_2$ are in scope.
A $z_2$-free replacement $s$ would be typed at $11$ and at $12$ in the same environment.
Then $s\{u_1/x_1, w/x_2\}$ would reduce both to $a$ and to $b$ (Lemma~\ref{lem:fifth-nolocal}).

The routes diverge at $\nu$ versus $\nu'$.
Both uses are opaque re-entries, since slot~2 contains the productive call $x_2$.
Copy re-calls at $\nu$ and $\nu'$ make $o$ garbage, and Lemma~\ref{lem:fifth-route} removes $n$.
A solution without far references is $\lambda x_1x_2.\,g\,(x_2\,R_a)\,(x_2\,R_b)$ with $R_e = x_1\,(\lambda z.\,z\,e)\,(\lambda z'.\,z'\,c)$.

\emph{Feature.}
Both judgements lie in one equation, so every $x_j$ denotes the same $u_1^j$ in both, and no re-call separates them.
The separating information (through which use slot~2 was entered) becomes syntactic only at $\nu$ and $\nu'$.
The resolution copies a productive continuation, so size grows.
\end{example}

\begin{example}[No Local Replacement without Divergence: Scope]\label{ex:ex-scope}
Let $\Phi = \{g : \bullet\to\bullet\to\bullet,\ a,b,c : \bullet\}$ and
\[
X : \big(((\bullet\to\bullet)\to\bullet) \to ((\bullet\to\bullet)\to\bullet) \to \bullet\big) \to ((\bullet\to\bullet)\to\bullet) \to \bullet
\]
(order~$5$).
Let
\[
u_1 = \lambda F_1F_2.\,F_1\,(\lambda y.\,F_2\,(\lambda y'.\,y)),
\qquad
u_2 = \lambda F_1F_2.\,F_1\,(\lambda y.\,F_2\,(\lambda y'.\,y')),
\qquad
w = \lambda H.\,g\,(H\,a)\,(H\,b).
\]
Take $X\,u_1\,w = g\,a\,b$, $X\,u_2\,w = g\,c\,c$ and
\[
t = \lambda x_1x_2.\,\underbrace{x_1\,(\lambda z_1.\,x_2\,(\lambda h.\,z_1\,h))\,(\lambda z_2.\,z_2\,c)}_{n}.
\]
In equation~1 we have $x_2 : \{1 \to 1,\ 2 \to 2\} \to \varepsilon$.
\begin{itemize}
\item $\nu_1 = z_1\,h$ has the judgements $h : 1,\ z_1 : 1 \to 1$ and $h : 2,\ z_1 : 2 \to 2$, both re-entries into slot~2.
\item $o = z_2\,c$ has the judgements $z_2 : \omega \to 1$ and $z_2 : \omega \to 2$, both outer returns with exit term $h$.
\end{itemize}
Both judgements of $o$ are routed through the same occurrence $\nu_1$, so they do not diverge.
Still, only $x_1, x_2, z_2$ are in scope at $o$, and $r_1|_1 = a \neq b = r_1|_2$, so no local replacement exists.
Lemma~\ref{lem:fifth-callfree} fails by (S2'): $h$ is bound by the productive node $x_2(\lambda h.\cdot)$ between $n$ and $\nu_1$.

At $\nu_1$, however, $h$ is in scope.
The judgements of $\nu_1$ are transparent re-entries, and the extended skeleton re-call is
\[
\nu_1 := x_1\,(\lambda z'_1.\,z'_1\,h)\,(\lambda z'_2.\,z'_2\,c).
\]
For $p \in \{1,2\}$ it is typed by $((p \to p) \to p) \to ((\omega \to p) \to p) \to p$ in equation~1, and by $((\omega \to p) \to p) \to ((p \to p) \to p) \to p$ in equation~2.
Afterwards slot~2 is no longer entered, and Lemma~\ref{lem:fifth-route} yields
\[
\lambda x_1x_2.\,x_2\,(\lambda h.\,x_1\,(\lambda z.\,z\,h)\,(\lambda z'.\,z'\,c)).
\]

\emph{Feature.}
The separating information is a black value, not a route choice: $\delta = 0$, yet the reference is not removable locally.
The uses separate inside a skipped black segment through a call of another main variable (cf.\ Lemma~\ref{lem:fifth-separator}).
Localisation must therefore process route occurrences (here $\nu_1$) before the final occurrence $o$.
\end{example}

\begin{remark}[Why Local Replacement Fails]\label{rem:ex-nolocal}
A replacement $s$ at $o$ is a term over the variables in scope at $o$.
In all judgements of equation $i$, each $x_j$ denotes $u_i^j$, and an introduced variable contributes only its type.
By the argument of Lemma~\ref{lem:fifth-nolocal}, applied after substituting the values of either judgement, the following holds.
If two judgements of $o$ in equation $i$ agree on the types of all variables free in $s$, then their targets $p, q$ satisfy $r_i|_p = r_i|_q$.

The separating information belongs to the evaluation context of $o$, not to its scope.
In the KAM it is the closure, in Stirling's game the look-up table, and in system~\textbf{R} the coordinate.
The examples exhibit four sources:
\begin{itemize}
\item the call of a parameter under a white constant (Example~\ref{ex:ex-white}): permanent, charged to white syntax;
\item re-entry depth with black output (Example~\ref{ex:ex-reentry}): permanent, charged to strict steps;
\item the occurrence through which a slot was entered (Example~\ref{ex:ex-clash}): resolved at the divergence by copy re-calls;
\item a black value out of scope at $o$ (Example~\ref{ex:ex-scope}): resolved under its binder by a skeleton re-call.
\end{itemize}
Variation between equations is not among them.
It is carried by the $x_j$, so re-calls recover it locally (Examples~\ref{ex:ex-canon}, \ref{ex:ex-shift} and~\ref{ex:ex-skeleton}).
\end{remark}

\begin{remark}[Consequences for Order~5]\label{rem:ex-consequences}~
\begin{itemize}
\item Re-calls for variation between equations are graded by the route.
A flat route keeps $B$ (Example~\ref{ex:ex-canon}).
Output on the black side only is retargeted (Example~\ref{ex:ex-shift}).
A route of length greater than~$1$ needs a skeleton (Example~\ref{ex:ex-skeleton}).
\item Unfolding is not occurrence-local.
Its site is the earliest route step at which the separating information is syntactic, so localisation proceeds upstream first.
\item Resolution may copy productive continuations, so termination is measured on judgements (Corollary~\ref{cor:fifth-termination}), not on term size.
Small solutions are obtained via width (Example~\ref{ex:ex-canon}).
\item Remaining far references are charged to white constants (Example~\ref{ex:ex-white}) or to black strict steps (Example~\ref{ex:ex-reentry}).
Both are bounded per branch, which is the intended shape of Lemma~\ref{lem:fifth-blocked}.
\item Dimension within one equation is driven by nesting under copying white sides (Example~\ref{ex:ex-instances}).
Bounding width and nesting therefore bounds dimension.
\item The shape of a re-call is fixed by targets and links.
It is not fixed by the types of introduced variables, which do not determine kinds (Example~\ref{ex:ex-skeleton}).
\end{itemize}
\end{remark}
